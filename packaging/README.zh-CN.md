# CalcTabdd 1.0.10 安装说明

1.0.10 版。提供普通、自定义和程序员计算，支持混合记录导出与 version 4 会话保存恢复。
程序员 `^` 为异或；普通／自定义仍表示乘方。第 3 版及更早会话不能直接恢复，不提供迁移。
有界十进制与近似混算支持普通／自定义计算、历史、ans、显示、复制、导出与本地会话。
十进制结果最多 50 位，近似结果最多 17 位；舍入、近似计算和转换损失在结果下方另行提示。

面向 notepad-- 的 Windows x64 标签页计算器。公式在上，结果在下；底部输入后按
Ctrl+Enter 或点击“计算”。普通／程序员模式 Enter 不提交，也不换行。错误会保留公式，“再次使用”可以回填历史。
回填后重新提交使用当前的 `ans`，追加新记录；已有公式与结果保持不变。

三种模式记录的“记录操作”菜单可复制纯数值、复制整条计算或插入结果数值。
纯数值不带 `=`，与显示的数字正文一致；整条复制包含公式、结果和非空来源说明，失败记录包含错误说明。
例如 `0.1+0.2` 显示并复制 `0.3`。长数软换行不改变复制的数字。
**纯数值复制／插入后按新十进制数字处理，不保留原类型和来源**。十进制数值可精确重输入；
近似文本转回 binary64 可恢复同位模式，但纯文本不能恢复其原近似类型或来源。有来源时操作后会提示这一边界。

插入使用当时的固定结果，替换输入框当前选区或插到光标处，支持撤销／重做；
普通／程序员模式负数带括号，例如普通模式插入 `-2` 后平方为 `(-2)^2`；自定义参数保留符号。
插入程序员前校验保存值本身为当前范围内整数，具体规则见下文。需要乘法时请显式输入 `*`。
复制／插入不提交计算、不改变 `ans`；失败记录没有纯数值复制或结果插入操作。

普通公式输入与自定义公式定义栏输入 `@` 可查找函数和常量，Enter/Tab 插入、Esc 关闭；支持英文名称和中文关键词。
普通／程序员输入框为空时，在框内显示示例和“@ 补全 · Alt+↑↓ 召回历史”，输入后自动隐藏。
自定义公式定义栏的空白提示包含示例和 @ 补全；参数框只提示逐行填写和 Alt+↑↓，不支持 @ 补全。
输入框外不再常驻快捷键说明；悬停“计算”可查看 Ctrl+Enter 快捷键。
计算成功、设置更新等普通反馈约 4 秒后自动清除；错误、缺少参数和未应用公式等需要处理的提示不会定时消失。
顶部操作栏“帮助”或插件菜单“运算与精度帮助”可搜索全部能力和精度说明。
插件菜单“关于 CalcTabdd”显示产品名称、版本、用途与开源许可。

## 自定义公式模式

1. 在底部输入区切换至 **自定义公式**，在参数区上方的 **公式定义栏** 直接输入 `A=x+y`，按 **Enter**（或点击“应用公式”）应用。
2. 输入框自动生成两行 `x=`、`y=`。每行填写一个参数，例如第一行 `x=1`、第二行 `y=2`。
3. 按 **Ctrl+Enter** 或点击“计算”。历史上方显示 `A=1+2`，下一行显示 `= 3`；参数值保留，方便继续修改。
   **填写、修改、停顿或切换焦点均不计算、不显示实时结果。** 每次确认独立新增记录，不改写旧记录。
4. 使用底部分段按钮切换 **普通计算／自定义公式／程序员**。三种模式分别保留草稿，自定义公式和参数切回时恢复。

模式按钮和“应用公式”可通过 Tab／Shift+Tab 聚焦、空格操作。窗口较窄时操作区自动换行；
高度不足时可滚动底部输入区，查看定义、填写参数或点击“计算”。顶部 ans 过长时省略显示，悬停可查看完整内容。
自定义模式保留“公式定义”和“填写参数”两个分区，不重复列出参数名称摘要；参数名直接在逐行输入中查看。

每个窗口保留一个当前公式。后续修改直接在公式定义栏输入，再按 **Enter** 应用；无需打开弹窗。修改定义时，同名参数保留值，新增参数留空，删除的参数移除；
修改定义后显示“未应用”；应用成功后该标签隐藏。未确认或无效的定义不会替换旧定义，并会阻止计算；按 **Esc** 还原已确认定义。首次定义时按 Esc 返回此前模式。公式支持全部现有数学运算、14 个函数、嵌套和 `pi`、`e`、`ans`；
例如 `S=pi*r^2`、`A=sqrt(x^2+y^2)+max(z,0)`。两个模式共享当前窗口上次成功的 `ans`。

公式名和参数名只使用英文字母、数字、下划线，不能数字开头，区分大小写；内置函数／常量名称保留。
参数值只填有符号数字、小数或科学计数法，例如 `-2`、`.5`、`1e3`，不填写 `1+2` 或另一参数名。
参数每行一个，参数区的普通 Enter 用于换行。普通公式输入与公式定义栏均支持 `@` 补全，数值参数区不启用。
例如在定义栏输入 `A=@sq`，按 Enter 选中 `sqrt()`，填写参数名 `x` 后再按 Enter 应用 `A=sqrt(x)`；
候选打开时 Enter／Tab 只插入候选，不会同时应用定义或计算。输入法组词期间不应用定义。
定义及代入后的表达式沿用计算引擎的长度、嵌套与数值限制。

- 缺少、重复、未知或非法参数只提示修正，不追加记录。同行填写多个参数时提示分行填写。完整参数引发除零、定义域或溢出错误时，
  沿用普通模式的错误历史，失败不更新 `ans`；自定义模式在状态区提示错误，不把代入式位置标到参数输入上。
- `A=x^2+y`，分两行填写 `x=-2`、`y=3` 后显示 `A=(-2)^2+3` 与 `= 7`，负数代入保留正确优先级。
- 自定义历史的“再次使用／修改公式”及 Alt+↑↓ 恢复当时的定义和参数；浏览中临时编辑保留，
  成功提交或向后越过最新记录后返回原草稿。手动切换模式会结束这轮浏览并恢复对应模式草稿。
- 复制整条计算、TXT／Markdown 导出包含名称、当次数值代入式和结果。复制纯数值采用与显示一致的数字正文，不继承原来源；
  插入自定义参数时使用有符号数字，普通模式插入负数继续带括号。
- 三种模式统一使用“本地会话”保存开关。默认不保存，关闭重开是空白普通模式；开启保存后，
  当前模式、三份草稿、两类 ans、程序员设置、已确认定义、参数和全部历史一起保存并恢复。尚未按 Enter 应用的定义修改只在当前窗口保留，不保存到文件；恢复使用最后确认的定义。保存或恢复不会重新计算历史结果。

## 程序员模式

从底部选择 **程序员**。输入框上方集中显示位宽、类型和“^ 异或”提醒；位宽可选 8、16、32、64 位，默认 **32 位无符号**。
有符号按补码解释；裸数字按十进制，`0x`／`0b`／`0o` 为十六／二／八进制位模式。
前缀和十六进制数字可用大小写，数字间可加下划线，如 `0XFFFF_FFFF`。
小数、科学计数法、科学函数及赋值不适用。

| 配置与输入 | 结果 |
| --- | --- |
| 16 位无符号 `(0x12 & 0x0F) << 4` | DEC 32，HEX `0x0020`，BIN `0000 0000 0010 0000`，OCT `0o40` |
| 8 位有符号 `0xFF` | DEC -1，HEX `0xFF`，BIN `1111 1111`，OCT `0o377` |
| 8 位有符号 `0x80>>1`、`0x80>>>1` | 分别 -64、64；`>>>` 始终补零 |
| 8 位无符号 `(255+1)/2` | 0，含 8 位回绕 |
| 64 位无符号 `0xFFFFFFFFFFFFFFFF` | 完整整数 `18446744073709551615` |

支持 `+ - * / % & | ^ ~ << >> >>>`、一元正负号和括号。
优先级从高到低为括号、一元 `+ - ~`、`* / %`、`+ -`、移位、`&`、`^`、`|`。
**程序员 `^` 为异或**，`2^3=1`；普通／自定义的 `2^3=8`。
整数除法向零截断，非零余数随被除数；移位量为 0 至位宽减 1。
字面量越界报错；运算逐步回绕，并保留“含 8 位回绕”等来源。
例如 8 位有符号 `-128/-1=-128` 且提示回绕，`-128%-1=0` 不新增回绕；
`-3>>1=-2`，而 `-3/2=-1`。8 位无符号 `-1=255` 且提示回绕，
直接输入 `256` 则报错。`>>>` 始终补零，结果仍按当前符号解释；移位量越界时不取模。

记录默认显示十进制和 HEX，点击 **展开进制详情** 查看 BIN／OCT。
HEX 补足位宽并使用大写数字；BIN 补足位宽、每四位分组；OCT 使用最短位模式。
展开详情或改变输入配置不会重算旧记录，也不会计算当前草稿。
整数 `ans` 与普通／自定义共享的数学 `ans` 独立，失败保留、清空重置。更改位宽或符号
不会立即转换整数 `ans`；实际引用时保持原数值和回绕来源，无法表示则报错并保留原值。
例如 16 位无符号得到 256 后切到 8 位，使用 `ans` 报越界；8 位无符号的 255
切到 8 位有符号后不能解释成 -1，切到 16 位有符号则仍为 255。
不引用 `ans` 的表达式可直接按新设置计算，成功后替换整数 `ans`。
三种模式分别保留当前窗口内的草稿、光标与选区，程序员草稿还保留位宽与符号。
历史回填恢复原配置，重新提交使用当前对应 `ans`，不会回滚到历史中的旧 `ans`。

程序员模式有以下 8 种补全模板；二元运算模板末尾保留空格，等待继续输入右操作数。

| 查询示例 | 插入文本 | 光标位置 |
| --- | --- | --- |
| `@上次结果` | `ans` | 名称之后 |
| `@取反` | `~()` | 括号内 |
| `0xFF @按位与` | `0xFF & ` | 运算符之后 |
| `0x10 @按位或` | `0x10 \| ` | 运算符之后 |
| `2 @异或` | `2 ^ ` | 运算符之后 |
| `1 @左移` | `1 << ` | 运算符之后 |
| `0x80 @算术右移` | `0x80 >> ` | 运算符之后 |
| `0x80 @逻辑右移` | `0x80 >>> ` | 运算符之后 |

Enter／Tab 仅插入候选，Esc 关闭；无候选时 Tab／Shift+Tab 切换焦点。
输入法组合态或未完成 `@` 查询时不能提交。普通 Enter 不换行，Ctrl+Enter／“计算”才提交。
帮助窗口按当前模式显示，也可在窗口内切换查看另一模式。程序员帮助可搜索“异或”“回绕”“ans”“会话”，
两个页签分别列出整数操作和范围限制；普通／自定义帮助继续提供数学函数和精度说明。

保存入口及说明集中在顶部“本地会话”和帮助中。开启保存后，程序员和数学记录、两类 ans、三份草稿与设置一起保留。
整数使用十六进制字符串保存位模式，完整保留位宽、符号及回绕来源，包括 64 位无符号最大值。
当前配置与整数 ans 的原配置分别保存；恢复后引用 ans 时才按当前配置检查数值范围。
保存默认关闭；关闭后从新的空白计算器手动恢复，历史结果不重新计算。

### 程序员复制与结果插入

- “复制纯数值”复制 DEC 正文，无 `=` 或分组。“复制 HEX／BIN／OCT”复制原记录位模式，
  带 `0x`／`0b`／`0o` 前缀；HEX 大写并补足位宽，BIN 补足位宽、去掉分组空格，OCT 最短。
  8 位有符号 -1 分别复制为 `-1`、`0xFF`、`0b11111111`、`0o377`。
- 纯文本不携带原位宽、符号或回绕来源。粘贴 `0xFF` 在 8 位有符号下为 -1，在 16 位无符号下为 255；
  手工粘贴仍受目标模式的输入语法及范围限制。
- “插入结果数值”固定插入保存的十进制数值，替换当前选区或插到光标处，支持撤销／重做。
  普通／程序员表达式的负数带括号，自定义参数使用有符号正文。
- 插入程序员前检查保存值本身是整数且在当前数值范围内；小数、负数转无符号或越界均拒绝，
  保留输入、选区和撤销记录，不四舍五入、不截小数、不重新解释位模式。
  例如 8 位有符号的 -1 插入 16 位有符号为 `(-1)`，插入无符号失败；255 插入 8 位有符号失败。
- 数学结果即使带舍入、近似或转换损失，只要实际保存值是范围内整数也允许插入，
  按新整数文本计算，不继承来源。负零插入程序员为 `0`。
  长近似整数使用保存的实际整数值，可能与 17 位显示文本不同：
  `18446744073709549568+sin(0)` 插入 64 位无符号为完整 `18446744073709549568`。
- “复制整条计算”包含原模式、位宽、符号、公式、DEC／HEX／BIN／OCT 和非空回绕来源；
  失败记录包含原配置、公式及错误，不附成功结果。详情折叠或当前设置改变不影响复制。

## 本地会话保存与恢复

普通、自定义和程序员模式共用本地会话入口，支持混合历史。

- 默认不保存。点击顶部操作栏 **本地会话 → 开启保存／另存新文件…**，选择本地目录和新文件名，
  首次默认打开“文档”目录，自动补 `.calctabdd` 后缀。首次保存成功后，当前标签才开启自动保存。
  已有文件不覆盖；要继续已有会话，请使用“恢复会话”。
- 开启后，提交计算和确认清空会话会立即保存，已上屏草稿、光标、选区和历史浏览状态在停止编辑
  约 200 毫秒后保存；切换标签、关闭标签或窗口销毁时也尝试保存最后更改。
  输入法尚未上屏的候选、文字撤销栈、滚动位置和帮助窗口不保存。
- 文件保留原公式、当时的类型化结果及来源、错误文字／分类／范围、计算前的 `ans`、两类当前 `ans`、三份草稿、光标、选区及
  历史浏览位置、原草稿和临时编辑，以及当前模式、程序员设置、已确认公式定义和参数。十进制保存规范数值文本，
  近似值保存原 binary64 位模式，两者均保留负零。整数保存十六进制字符串位模式、位宽、符号和回绕来源；成功结果的显示由保存值重新生成，**不会重新计算旧公式**。
- 关闭标签或退出后，已保存文件仍保留。重开计算器默认是空白页，通过 **本地会话 → 恢复会话…**
  选择该文件；恢复成功即继续自动保存到该文件。恢复要求当前页为空白普通模式，没有记录、三模式草稿、自定义定义或修改过的程序员设置，且未开启保存，
  不会替换正在使用的会话。恢复后提交新公式继续使用已保存的 `ans` 和下一编号。
- 每个窗口独立选择文件。同一个文件同时只允许一个 CalcTabdd 窗口／进程打开，其他窗口会提示占用。
  关闭持有会话的标签后可在另一窗口恢复；只切换到普通文档仍保留文件占用。
  文件以可读的 UTF-8 JSON 保存；保存目录中的 `.lock` 文件用于占用保护，正在使用时不要删除它。
- **立即保存／重试** 可主动保存。写入失败会持续显示原因，当前记录和草稿仍在；可以重试，或另存到
  新文件。文件被外部修改、损坏或格式版本不受支持时，不覆盖原文件、不作部分恢复。
  新建／另存失败会保留原保存状态和当前内容。文件完整写入后才替换目标，不回退到直接截断旧文件。
- **停止保存（保留文件）** 会先保存最后更改，再释放文件；失败时继续保留当前保存状态。
  后续计算只在标签中保留，原文件不删除。开启保存时，**清空会话也会更新保存文件**，确认框会提示，
  不提供历史文件回收站或清空撤销。
- 会话只读写当前 **version 4** 完整格式；**version 3 及更早文件不能直接恢复**，未知版本也拒绝，不修改原文件。不提供旧格式迁移或版本回退。
  单个保存文件最多 16 MiB、10000 条记录，超限时保留当前可见内容并提示，可先导出记录。
  TXT／Markdown 导出仍用于阅读，不能作为会话文件恢复。
- 保存成功前不要关闭标签；若磁盘、权限等问题持续存在，强制关闭仍会丢失未成功写入的更改。
  异常终止最多恢复最后成功保存的快照，不承诺尚未保存的输入、断电或所有文件系统上的持久性。
  文件位于用户选择的位置，卸载 DLL 不会删除这些文件。

## 导出计算记录

支持普通、自定义和程序员混合历史。每条记录使用当时保存的数值、配置和计算来源。

- 点击顶部操作栏 **导出记录**，选择 **导出为 TXT…** 或 **导出为 Markdown…**，再选择文件位置。
  没有填写扩展名时自动补 `.txt` 或 `.md`；已有文件需要再次确认覆盖，默认取消。
- 导出当前窗口的全部已提交记录，按编号顺序保留原公式、当时的成功结果和失败时的错误说明。
  不重新计算含 `ans` 的旧公式，不导出尚未提交的草稿或历史公式的临时编辑。
- 数学成功结果与显示、整条复制共用数值正文：十进制最多 50 位，近似值最多 17 位，保留负零并附非空来源说明。
  例如 `0.1+0.2` 导出为 `0.3`；`1/3` 导出完整 50 位结果及“含除法舍入”。不通过重算生成文本。
- 程序员记录包含原模式、位宽、符号、公式、DEC／HEX／BIN／OCT 四种结果及非空回绕来源，
  详情是否展开不影响导出。失败记录包含原配置、公式和错误，不伪造结果；大于 2^53 的整数完整保留。
- 两种格式均为 **UTF-8（无 BOM）**、LF 换行。TXT 使用编号和分行文本；Markdown 使用分节与
  代码块，中文、换行、反引号、HTML 和其他特殊字符按原文保留。
- 成功、取消或失败均不改变记录、`ans`、草稿、选区、撤销记录及历史浏览状态。
  写入失败时状态栏显示原因，记录仍保留；可再次点击同一导出入口重试或另选位置。
  文件完整写入后才替换目标，无法完成保存时不以直接截断方式覆盖旧文件。
- 空会话或中文输入法组词期间导出按钮不可用。导出窗口仅限制所属宿主窗口，其他窗口仍可计算；
  切换到普通文档、关闭计算器标签或关闭所属窗口会取消未完成的导出。
  导出文件供阅读和留存，当前没有从 TXT／Markdown 恢复计算会话的功能。

## 错误定位与修正

- 普通模式计算失败时，输入框用底色和波浪线标记问题字符、参数或运算符，光标移到问题处，
  状态栏显示行号和列号。前导空白、多行与 Unicode 运算符均计入定位；输入全文保留。
- 末尾缺少右括号或操作数时，光标停在应补充内容的位置，并突出所在行。
  标记只用于提示，不会自动选中文字；继续输入不会替换整段错误参数。
- `ln(0)`、`log(-1)` 提示参数必须大于 0，`sqrt(-1)` 提示参数必须大于或等于 0。
  负底数的非整数次幂、0 的负数次幂会解释实数定义域限制；`0^0` 沿用结果 `1`。
  函数参数不足／过多、未知名称、除零与溢出各有对应提示。
- 编辑、开始输入法组词或确认清空会话后，旧标记消失；重新提交时重新定位。
  通过“修改公式”或 Alt+↑↓ 回填未修改的错误公式时显示该条的历史诊断；
  临时修改公式或程序员位宽／符号后须重新计算，不沿用旧配置下的错误标记。
- 失败会保留上次成功结果 `ans`，修正后提交追加新记录。原错误记录继续保留。

## 历史召回与草稿

记录超过 100 条时分页显示，默认展示最近 100 条，通过 **较早记录 / 较新记录** 查看其他记录。翻页保留当前草稿和选区；分页不裁剪历史，保存、导出和 **Alt+↑ / Alt+↓** 召回仍覆盖全部记录。

- 在底部输入框按 **Alt+↑** 从最新一条向前召回，按 **Alt+↓** 向后浏览；
  向后越过最新一条会返回召回前的草稿。最旧处不循环，无历史时不改变输入。
- 首次召回保存原模式、草稿全文、光标和选区，包含空白及粘贴的多行内容；程序员草稿还保存位宽与符号。
  浏览期间各条公式的临时编辑及设置会保留，返回草稿或成功提交后结束本轮浏览；原历史记录始终不变。
- 召回后可修改，按 **Ctrl+Enter** 或点击“计算”才追加计算，使用当前对应领域的 `ans`，不恢复历史中的旧值。
  成功后返回原草稿；失败保留公式、设置和错误位置，可修正后重试。“再次使用 / 修改公式”也采用此规则。
- 手动切换模式会结束浏览，恢复对应模式的原草稿。首次切到自定义定义栏也采用此规则；
  此时 Esc 返回召回前的原草稿，而不是历史临时编辑。
- 普通 ↑↓ 继续移动光标，Shift+方向键继续选择文字。输入法组词或 `@` 候选打开时，
  Alt+↑↓ 不召回历史；可先完成组词或按 Esc 关闭补全，再召回。
- 切换浏览项会重置输入框撤销栈；当前项的文字编辑和结果插入仍可撤销／重做。
  未开启本地保存时，草稿和临时编辑在关闭标签或退出后清空；开启后可从会话文件恢复。

## 清空会话

- 点击顶部操作栏 **清空会话**，确认后删除当前窗口的全部成功和失败记录，数学与整数 `ans` 均重置为 `0`，
  下一条记录从 `01` 开始。清空后可以继续计算；其他窗口的记录、结果和草稿不受影响。
- 三种模式的原草稿、光标、选区和程序员设置保留，当前输入的文字撤销记录也保留。若正在浏览历史公式，则返回召回前的
  原始草稿及选区，并丢弃本轮历史公式的临时编辑；确认框会明确提示这一点。
- 确认框默认选择“取消”，按 Esc 或关闭确认框也会取消，原会话保持不变。
  **清空记录不可撤销**，没有单条删除功能；输入框的文字撤销不会恢复计算历史。
- 没有记录或输入法正在组词时，“清空会话”不可用；完成组词后可以操作。
  草稿中的 `ans` 在清空后会引用 `0`，例如保留 `ans+1` 再计算会得到 `1`。

## 安装

1. 退出所有 notepad-- 窗口。
2. 把本包的 `plugin/calctabdd.dll` 放入 notepad-- 安装目录的 `plugin` 子目录。
3. 启动宿主，选择“插件 → CalcTabdd 计算器 → 打开计算器”。

目标运行库为 Qt 5.15.2 / MSVC v142，架构 x64。请不要覆盖宿主的 Qt DLL。
每个宿主窗口独立保留计算历史；重复打开会返回已有标签。默认关闭后清空，开启本地保存后可从文件恢复。

支持 `+ - * / % ^`、括号、小数、科学计数法、`pi` / `e` / `ans`，以及
`sqrt`、`abs`、`sin`、`cos`、`tan`、`ln`、`log`、`exp`、`floor`、`ceil`、`round`、
`min`、`max`、`pow`。`%` 为取余，三角函数采用弧度。
十进制最多 50 位规范化有效数字，非零科学指数 -999 至 999；加减乘逐节点精确、超限报错。
每次除法最多保留 50 位，取最近值、恰好居中时让末位为偶数。`1/3` 会舍入，有限小数商超过 50 位时
也会舍入，例如 `1/(2^100)`；`(1/6)*6` 仍因后续精确乘法超限报错。
`0.1+0.2=0.3`、`0.3%0.1=0`、`1e-200*1e-200=1e-400`；`1e-1000` 拒绝输入。
整数幂指数绝对值最多 10000；负整数幂先求正幂再除，`2^-200` 因中间正幂超限失败。
有限精确平方根保留十进制；科学函数、pi/e、非整数幂及其余平方根使用 binary64。
`ln(1e400)`、`sin(1e-400)` 拒绝不安全转换；`exp(-1000)` 拒绝非零结果下溢为零。
来源按“含除法舍入；含近似计算；含转换损失”顺序展示，零和整数也保留上游来源；标记不是误差估计。
近似显示最多 17 位不代表 17 位准确度；重新计算的科学函数可能跨平台末位不同。
科学指数 -6 ≤ E < 21 使用普通小数，其余用小写 e 和有符号指数；不补无意义尾零，负零始终为 -0。
`ans` 和 version 4 会话完整保留类型、数值和来源。不提供任意精度或统一误差上限。

计算器标签激活时，宿主编辑菜单与主工具栏的复制、剪切、粘贴、撤销和重做作用于计算器输入或选中的历史文本。选中历史文本后粘贴会返回输入区；若正在编辑尚未应用的公式定义，粘贴到定义栏，不修改参数或隐藏草稿。
保存、另存为和查找替换等文档命令不可用；计算器标签右键菜单只提供关闭及保存入口提示，保存请使用页面内“本地会话”或“导出记录”。切回普通文档恢复宿主命令与工具栏。

本包包含使用检查清单 `TESTING.md`、变更说明 `CHANGELOG.md`、构建信息 `BUILD-INFO.json`
与许可证 `LICENSE`。可按清单确认插件在当前宿主中的使用情况。

卸载：退出宿主后删除 `plugin/calctabdd.dll`。
