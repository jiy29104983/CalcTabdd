# CalcTabdd 0.2.3 测试版安装说明

面向 notepad-- 的 Windows x64 标签页计算器。公式在上，结果在下；底部输入后按
Ctrl+Enter 或点击“计算”。普通 Enter 不提交。错误会保留公式，“再次使用”可以回填历史。
回填后重新提交使用当前的 `ans`，追加新记录；已有公式与结果保持不变。

每条记录的“记录操作”菜单可复制纯数值、复制整条计算或插入历史结果。
纯数值不带 `=`；整条复制包含公式和下一行的结果，失败记录包含错误说明。
数值复制和插入使用最多 17 位有效数字，可还原同一内部值；界面仍最多显示 15 位。
例如 `0.1+0.2` 显示 `0.3`，复制纯数值为 `0.30000000000000004`。

插入使用当时的固定结果，替换输入框当前选区或插到光标处，支持撤销／重做；
负数带括号，例如插入 `-2` 后平方为 `(-2)^2`。需要乘法时请显式输入 `*`。
复制／插入不提交计算、不改变 `ans`；失败记录没有纯数值复制或结果插入操作。

输入 `@` 可查找函数和常量，Enter/Tab 插入、Esc 关闭；支持英文名称和中文关键词。
右上角“帮助”或插件菜单“运算与精度帮助”可搜索全部能力和精度说明。
插件菜单“关于 CalcTabdd”显示版本与宿主兼容参考。

## 历史召回与草稿

- 在底部输入框按 **Alt+↑** 从最新一条向前召回，按 **Alt+↓** 向后浏览；
  向后越过最新一条会返回召回前的草稿。最旧处不循环，无历史时不改变输入。
- 首次召回保存草稿全文、光标和选区，包含空白及粘贴的多行内容。
  浏览期间各条公式的临时编辑会保留，返回草稿或成功提交后结束本轮浏览；原历史记录始终不变。
- 召回后可修改，按 **Ctrl+Enter** 或点击“计算”才追加计算，使用当前 `ans`。
  成功后返回原草稿；失败保留公式和错误位置，可修正后重试。“再次使用 / 修改公式”也采用此规则。
- 普通 ↑↓ 继续移动光标，Shift+方向键继续选择文字。输入法组词或 `@` 候选打开时，
  Alt+↑↓ 不召回历史；可先完成组词或按 Esc 关闭补全，再召回。
- 切换浏览项会重置输入框撤销栈；当前项的文字编辑和结果插入仍可撤销／重做。
  草稿和临时编辑仅属于当前标签，关闭标签或退出后清空。

## 安装

1. 退出所有 notepad-- 窗口。
2. 把本包的 `plugin/calctabdd.dll` 放入 notepad-- 安装目录的 `plugin` 子目录。
3. 启动宿主，选择“插件 → CalcTabdd 计算器 → 打开计算器”。

目标运行库为 Qt 5.15.2 / MSVC v142，架构 x64。请不要覆盖宿主的 Qt DLL。
每个宿主窗口独立保留计算历史，关闭标签或退出后清空；重复打开会返回已有标签。

支持 `+ - * / % ^`、括号、小数、科学计数法、`pi` / `e` / `ans`，以及
`sqrt`、`abs`、`sin`、`cos`、`tan`、`ln`、`log`、`exp`、`floor`、`ceil`、`round`、
`min`、`max`、`pow`。`%` 为取余，三角函数采用弧度，数值为双精度浮点。

计算器标签激活时保存、另存为和查找替换等文档命令不可用；切回普通文档恢复。

本包包含使用检查清单 `TESTING.md`、变更说明 `CHANGELOG.md`、构建信息 `BUILD-INFO.json`
与许可证 `LICENSE`。可按清单确认插件在当前宿主中的使用情况。

卸载：退出宿主后删除 `plugin/calctabdd.dll`。
