# CalcTabdd 0.2.2 使用检查清单

用于确认插件在当前 Windows x64 notepad-- 环境中的安装和使用。

## 安装

1. 确认使用 Windows x64 版 notepad--，Qt 运行库为 5.15.2。
2. 退出所有 notepad-- 窗口。将包中 `plugin/calctabdd.dll` 复制到 notepad-- 安装目录的
   `plugin` 子目录。升级时先备份同名 DLL；不要覆盖宿主的 Qt DLL。
3. 启动 notepad--，打开 **插件 → CalcTabdd 计算器 → 打开计算器**。
4. 若未出现菜单，记录宿主完整版本、架构、DLL 放置路径和任何错误提示。

## 功能与界面

- 公式在上、结果在下，底部输入区始终可用；改变窗口大小后布局完整。
- `1+2*3` 应得到 `7`；`(1299+899)*0.85` 应得到 `1868.3`；`sqrt(9)` 应得到 `3`。
- `Ctrl+Enter` 和 `Ctrl+小键盘 Enter` 均提交；普通 Enter 不提交；点击“计算”也可提交。
- 成功后输入清空；`12/(3-3)` 显示除零错误并保留输入；修改后可以继续计算。
- “再次使用 / 修改公式”正确回填原公式；选中结果后能复制。
- 连续输入足够多条记录后滚动到最新结果，也能向上阅读旧记录。
- `ans` 引用上一条成功结果，失败计算不更新 `ans`。

## 计算记录回归

- 依次提交 `6*7`、`1/0`、`ans+1`，记录编号为 01、02、03，分别显示 42、除零错误、43。
- 对第三条 `ans+1` 点击“再次使用”并提交，新增第四条结果 44；第三条仍为 43。
- 对失败记录点击“修改公式”，原公式正确回填；修正后新增成功记录，旧错误记录仍保留。
- 追加多条记录后再回填较早的公式，公式内容与原记录一致。
- 第二个窗口首次计算 `ans` 得到 0；关闭并重开第一个窗口的计算器也从 0 开始，
  首条记录编号为 01，第二个窗口原有记录与 `ans` 保持不变。

## 复制与插入历史结果

- 计算 `0.1+0.2`，界面显示 `0.3`。在该条“记录操作”菜单选择“复制纯数值”，
  粘贴得到 `0.30000000000000004`，不含 `=`。输入该数值减 `ans`，结果应为 `0`。
- “复制整条计算”得到原公式和下一行 `= 0.30000000000000004`；复制不改变输入区的草稿及选区。
- 计算 `-2`，输入 `99^2` 并选中 `99`，在负数记录菜单选择“插入历史结果”：
  输入变为 `(-2)^2`，提交后得到 `4`。撤销应恢复 `99^2`，重做应恢复 `(-2)^2`。
- 在公式中间插入时前后文字保留，插入完成后焦点回到输入区；菜单和快捷键撤销／重做均有效。
- 后续计算改变 `ans` 后，再从旧记录插入，仍使用该条当时的结果。插入本身不新增记录或修改 `ans`。
- 对 `1/0` 的失败记录打开菜单，只提供“复制整条计算”，内容包含原公式与错误说明；
  没有“复制纯数值”或“插入历史结果”，原“修改公式”仍可用。
- 计算 `-0` 后纯数值复制为 `-0`、插入为 `(-0)`；计算 `1e-200*1e-120`，复制的科学计数数值可重新计算。
- 中文组词中不因菜单插入丢失预编辑文字；完成组词后可插入。使用 `@` 补全后再操作记录菜单，输入正常。
- 在第二窗口操作记录，第一窗口草稿与历史保持不变；切回普通文档后编辑命令正常，关闭重开无残留菜单。
- 明暗主题、窄窗口及 100% / 150% / 200% DPI 下，“记录操作”和菜单文字可读、可点击。

## 帮助、补全与关于

- 右上角“帮助”和插件菜单“运算与精度帮助”打开同一窗口；可边看帮助边编辑公式。
- 搜索 `sqrt`、`平方根`、`取余`、`精度`、`非正规数`；确认运算、精度两页均能查询，清空恢复全部内容。
- 输入 `@` 列出全部 17 个函数／常量；输入 `@sq`、`@平方根`、`@对数`、`@上次` 正确筛选。
- ↑↓ 选择，Enter/Tab 与鼠标插入，Esc 关闭且保留文字；关闭后普通 Enter 不提交。
- 在 `2+@sq*3` 中补全得到 `2+sqrt()*3`，光标进入括号；`@pow` 得到 `pow(, )`。
- 在 `2+@sq(9)*3` 中补全保留已有 `(9)`；撤销／重做不破坏前后公式。
- `8/4`、`1e3` 和直接输入 `sin(pi)` 不弹候选；未完成 `@` 查询时 Ctrl+Enter 和计算按钮不提交记录。
- 中文输入法正在组词时，Enter、方向键等优先用于输入法候选；“平方根”上屏后再显示函数候选。
- 打开补全后切换标签、切到其他窗口、关闭标签或退出，无残留候选或崩溃。
- “关于 CalcTabdd”显示 0.2.2、目标运行库和 v3.8.3 / v3.9.0 源码参考，并说明源码参考与实际宿主兼容性的区别。
- 帮助、关于和候选窗口在明暗主题及 100% / 150% / 200% DPI 下文字可读、不越出屏幕。

## 宿主行为

- 切到普通文档再切回，记录保留、焦点回到输入区，普通文档内容不变。
- 重复打开计算器会回到现有标签；两个宿主窗口的历史互不影响。
- 计算器激活时测试菜单和快捷键复制、粘贴、剪切、全选、撤销、重做。
- 计算器激活时保存、另存为、查找替换不可用；切回普通文档后恢复。
- 分别测试关闭当前、关闭其他、关闭左/右侧、关闭全部。
- 有其他未保存文档时测试退出、取消退出、再次退出，确认计算器不导致额外空白文件保存提示。
- 关闭计算器后重开应为空历史；退出和重启后不恢复计算记录。
- 启用宿主会话恢复后，确认没有崩溃或文档污染；底层未命名空标签可能按宿主规则恢复，
  不应误认为计算历史恢复。

## 系统体验

- 中文输入法预编辑、候选确认，以及输入后继续计算。
- 明暗主题、100% / 150% / 200% 缩放、跨显示器移动。
