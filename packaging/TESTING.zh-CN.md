# CalcTabdd 1.0.0 使用检查清单

用于确认插件在当前 Windows x64 notepad-- 环境中的安装和使用。

本版已启用有界十进制完整用户流程。按下列新规则检查，特别是长数字、来源提示、纯数值重新输入和 version 3 会话。

## 安装

1. 确认使用 Windows x64 版 notepad--，Qt 运行库为 5.15.2。
2. 退出所有 notepad-- 窗口。将包中 `plugin/calctabdd.dll` 复制到 notepad-- 安装目录的
   `plugin` 子目录。升级时先备份同名 DLL；不要覆盖宿主的 Qt DLL。
3. 启动 notepad--，打开 **插件 → CalcTabdd 计算器 → 打开计算器**。
4. 若未出现菜单，记录宿主完整版本、架构、DLL 放置路径和任何错误提示。

## 功能与界面

- 公式在上、结果在下，底部输入区始终可用；改变窗口大小后布局完整。
- `1+2*3` 应得到 `7`；`(1299+899)*0.85` 应得到 `1868.3`；`sqrt(9)` 应得到 `3`。
- `Ctrl+Enter` 和 `Ctrl+小键盘 Enter` 均提交；普通 Enter 不提交；点击“计算”也可提交。
- 普通新公式成功后输入清空，历史召回成功后返回原草稿；`12/(3-3)` 显示除零错误并保留输入；修改后可以继续计算。
- “再次使用 / 修改公式”正确回填原公式；选中结果后能复制。
- 连续输入足够多条记录后滚动到最新结果，也能向上阅读旧记录。
- `ans` 引用上一条成功结果，失败计算不更新 `ans`。

## 自定义公式

- 模式下拉菜单仅显示“普通计算模式”和“自定义公式模式”，没有重复的定义／修改入口或多余分隔线；直接点击定义栏编辑公式。
- 底部模式菜单选择“自定义公式模式”，在页面内公式定义栏输入 `A=x+y`，按 Enter 应用。检查自动生成 `x=`、`y=` 两行；
  分两行填写 `x=1`、`y=2`，停顿、换行、切换焦点不出现结果。Ctrl+Enter 后新增 `A=1+2`，下一行 `= 3`，参数保留。
- 后续在同一公式栏修改定义，未按 Enter 应用时不能计算旧定义；无效定义显示错误、保留原参数和历史。Esc 还原已确认定义。
- 在定义栏输入 `A=@sq`／`A=@平方根`，Enter 先插入 `sqrt()`，输入 `x` 后再次 Enter 应用；不直接新增计算记录。
  检查 Tab／鼠标选候选、已有括号保留、撤销重做、等号后补全；参数数值输入区不弹候选。
- 将两行修改为 `x=4`、`y=5` 后确认新增 `A=4+5 = 9`，旧记录保持 3；重复确认再增加一条。
  测试三行 `A=sqrt(x^2+y^2)+max(z,0)`，填写 3、4、2 得到 7；更多参数可滚动填写。
- 测试 `A=x^2+y` 分两行填写 `x=-2`、`y=3`，代入式为 `A=(-2)^2+3`，结果 7；科学计数法及同名前缀参数正确。
- 同行填写 `x=1 y=2` 或用 Tab 分隔多个参数，提示“每行只能填写一个参数”，不新增记录且不更新 ans；
  改为每行一个参数后正常计算。缺少、重复、拼错参数名或填写 `x=1+2` 时不新增历史。`A=1/x` 填 0，确认后记录除零错误；
  `ans` 保持上次成功值，改为有效参数后可继续计算。
- 普通模式先留草稿和选区，切自定义后填写参数，再切回，两份输入分别恢复。重新定义保留同名参数，
  新增参数留空；无效定义、取消、Esc 不替换旧定义。历史回填恢复当时定义与参数，返回草稿完整恢复原模式。
- 混合普通和自定义历史后复制／导出，检查自定义名称、代入式、结果；纯数值和参数值插入可继续计算。
- 开启本地保存，分别在普通模式、自定义模式、历史浏览中关闭并恢复，检查两份草稿、模式、定义、
  参数、既有结果和临时编辑。定义栏未确认的修改仅在当前窗口保留，保存并恢复后应使用已确认定义。恢复不重新计算。只验证当前完整会话结构的保存和恢复。
- 测试保存失败和另存救回两种模式状态；默认不保存时关闭重开应是空白普通模式。
- 两个宿主窗口定义不同公式，互不影响。定义栏补全打开时切换普通文档、关闭标签或退出，无残留候选；
  普通文档内容、原生缓冲区与编辑命令正确。中文组词时不应用定义、不计算未上屏参数，Enter／Ctrl+Enter 分工正确。
- 检查明暗主题、窄窗口、100%／150%／200% DPI 下定义、模式菜单及多行参数可读可操作。
- 定义 `A=x+x`，填写较长但合法的数字，使代入式超过 4096 个 UTF-16 代码单元：应提示代入后的公式过长，
  不新增记录、不改变 ans；缩短参数后可以再次提交。符号及代入括号计入长度。

## 本地会话保存与恢复

- 保持默认未开启保存，计算后关闭并重开应为空白。开启保存选择新的中文目录／文件名，
  验证 `.calctabdd` 后缀与成功提示；选择已有文件应拒绝覆盖。取消、Esc、关闭文件选择框不改变会话。
- 依次计算 `0.1+0.2`、`ans+1`、`ln(0)`，保留多行中文／emoji 草稿及选区；召回公式并临时编辑，
  开启保存。关闭标签，在空白计算器中恢复：结果、来源、错误范围、ans、草稿、选区与临时编辑一致，成功显示由保存值生成。
  Alt+↓ 返回原草稿；再次提交 `ans+1` 追加新编号，旧公式不重新计算。
- 修改已上屏草稿，等自动保存后退出宿主；重启后显式选择文件恢复。另测修改后立即关闭标签／窗口，
  正常退出应尝试保存最后更改。输入法未上屏候选和文字撤销栈不要求跨启动恢复。
- 两个窗口各保存到不同文件，交替计算、清空及关闭，另一窗口不受影响。同一文件在使用期间拒绝
  第二窗口／进程恢复或另存覆盖；只切换普通标签不释放占用，关闭标签后允许另一窗口恢复。
- 保存文件暂时不可访问时提交公式，记录和草稿仍保留，独立提示区显示失败；不要关闭标签，修复后
  点“立即保存／重试”，或者“另存新文件”。另存失败不影响原会话，成功后继续向新文件保存。
- 对副本截断 JSON、修改格式版本或破坏记录编号，恢复应提示失败，不改原文件与当前页面。
  已开启保存的文件若被外部修改，再保存应拒绝覆盖，可另存救回当前内容。
- 停止保存先写入最后草稿并保留文件，后续计算不再更新该文件；恢复该文件后自动保存重新开启。
  清空确认应提示更新保存文件；确认后记录与 ans 清空、原草稿保留，关闭恢复仍为空历史。
- 中文组词期间不能打开会话文件选择框；`@` 候选进入选择框后收起。弹窗切换标签／关闭窗口后不残留。
  验证明暗主题、窄窗口、DPI 下菜单和保存错误提示可读，普通文档和宿主编辑命令不受影响。

- 分别保存并恢复 `0.1+0.2`、`-0`、`floor(1/3)` 和 `sin(1/3)` 的会话，检查完整数值、符号和来源；
  0.3 恢复后 `ans-0.3=0`，近似结果恢复后不重新计算。两模式草稿／参数原文均保留。
- 在副本上将版本改为 1、2 或未知值，应拒绝恢复；修改数值对象的类型、位模式或来源组合也应拒绝。
  不做旧格式迁移、不修改原文件，不部分替换当前页面。

## 导出计算记录

- 依次计算 `0.1+0.2`、`ans+1`、`1/0`、`-0`，分别导出 TXT 与 Markdown。
  文件按编号顺序包含原公式、当时的结果或错误；首条结果为 `0.3`，负零保留 `-0`。
  第二条仍为当时的结果，不能随当前 `ans` 变化而重算。
- 提交含中文、emoji、换行、反引号和 HTML 的无效公式。导出后检查 UTF-8 中文内容完整，
  Markdown 中原文字留在代码块内，不变成标题、表格或 HTML；在 Markdown 预览中复核。
- 保留草稿并选中一段后导出，草稿、选区和文字撤销／重做不变。浏览历史时修改临时公式，
  导出内容仍是原记录；继续 Alt+↑↓ 浏览并返回草稿，原草稿和选区应保持。
- 取消文件选择、按 Esc 或关闭对话框，不创建文件、不改当前会话。使用中文目录与中文文件名，
  不填后缀时分别补 `.txt`／`.md`；选择已有文件时默认取消，明确确认覆盖后才更新文件。
- 在无法写入的位置尝试导出，状态栏应说明失败原因，记录不丢失；修复权限或选择其他目录后重试。
  旧文件在未完成保存时应保持，不产生部分内容覆盖。空会话不可导出；只有失败记录时仍可导出。
- `@` 候选打开时进入导出，候选收起且草稿保留；中文组词期间导出按钮不可用，完成组词后恢复。
- 第一窗口选择导出位置或等待覆盖确认时，第二窗口仍可计算，导出文件只含第一窗口的记录。
  切到普通文档、关闭标签、关闭窗口后不残留导出对话框；未显式恢复会话时，重开计算器不恢复旧记录。
- 明暗主题、窄窗口和 100% / 150% / 200% DPI 下检查导出入口、文件选择、覆盖确认和失败提示可读。

## 错误定位与数值边界

- 先计算 `42`，再输入 `ln(0)`：标记参数 `0`，提示参数必须大于 0；随后计算 `ans+1` 得到 43。
  `log(-1)` 和 `sqrt(-1)` 分别解释正数／非负数限制；`(-8)^(1/3)`、`0^-1` 解释乘方定义域。
- 对 `(2+3`、`sqrt(9`、`1+`，光标停在末尾插入点，突出所在行；补全内容后可以计算。
  `2+$3` 标记 `$`；`what()` 标记未知名称；`min(1)`、`pow(,2)` 和 `sqrt(1,2)` 指出参数问题。
- 粘贴含前导空格、换行的 `ln(0)`，确认位置计入空白且不改原输入；粘贴 `2+😀`，标记完整字符。
  `12/(3-3)` 标记整个除数 `(3-3)`；`1e999*10` 指向溢出运算，`1e1000` 指向数值字面量。
- 错误标记不是实际选区，继续输入不替换整段参数；编辑、撤销或开始中文组词后移除旧标记。
  再提交重新定位；召回未修改的错误公式显示原诊断，浏览临时编辑时不套用旧范围。
  切换标签后同一公式仍保留标记；清空会话后标记消失，另一窗口输入与标记不受影响。
- `(2^53+1)-2^53` 得到 1；`9007199254740994-9007199254740992` 得到 2；
  `(1e16+1)-1e16` 和 `(1e16-1e16)+1` 均得到 1；`0.1+0.2=0.3`、`(0.1+0.2)-0.3=0`。
- `-5.5%2=-1.5`、`5.5%-2=1.5`、`0.3%0.1=0`，显示与复制完全一致。
- `1e-400` 合法；`1e-200*1e-200=1e-400`，负数版本为 `-1e-400`；
  `1e-999/10`、`1e-1000` 提示下溢并保持 ans。`sin(1e-400)` 拒绝转换下溢；`ln(1e400)` 拒绝转换上溢。
- `1/8=0.125` 无来源行；`1/3` 为小数点后 50 个 3，来源“含除法舍入”；`(1/6)*6` 报精度超限。
  `floor(1/3)=0` 保留舍入来源，`sin(0)=0` 保留近似来源，`sin(1/3)` 同时保留三种来源且顺序固定。
- `sqrt(0.09)=0.3` 无来源行；`pi` 显示 `3.1415926535897931` 并含近似计算。
  `2^-200` 拒绝中间正幂超限；`exp(-1000)` 拒绝下溢。成功近似值不能被说明为 17 位准确度。
- `1e-6` 显示 `0.000001`、`1e-7` 显示 `1e-7`、`1e20` 显示 21 位整数、`1e21` 显示 `1e+21`；
  `1.2300` 显示 `1.23`、`1000.00` 显示 `1000`、`-0.000` 显示 `-0`，原公式及参数原文不变。
- 明暗主题、窄窗口及 100% / 150% / 200% DPI 下，错误底色、波浪线、状态文字和末尾插入点可读。

## 计算记录回归

- 依次提交 `6*7`、`1/0`、`ans+1`，记录编号为 01、02、03，分别显示 42、除零错误、43。
- 对第三条 `ans+1` 点击“再次使用”并提交，新增第四条结果 44；第三条仍为 43。
- 对失败记录点击“修改公式”，原公式正确回填；修正后新增成功记录，旧错误记录仍保留。
- 追加多条记录后再回填较早的公式，公式内容与原记录一致。
- 第二个窗口首次计算 `ans` 得到 0；关闭并重开第一个窗口的计算器也从 0 开始，
  首条记录编号为 01，第二个窗口原有记录与 `ans` 保持不变。

## 复制与插入结果数值

- 计算 `0.1+0.2`，界面显示 `0.3`。在该条“记录操作”菜单选择“复制纯数值”，
  粘贴得到 `0.3`，不含 `=`。输入该数值减 `ans`，结果应为 `0`。
- “复制整条计算”得到原公式和下一行 `= 0.3`；复制不改变输入区的草稿及选区。
- 计算 `-2`，输入 `99^2` 并选中 `99`，在负数记录菜单选择“插入结果数值”：
  输入变为 `(-2)^2`，提交后得到 `4`。撤销应恢复 `99^2`，重做应恢复 `(-2)^2`。
- 在公式中间插入时前后文字保留，插入完成后焦点回到输入区；菜单和快捷键撤销／重做均有效。
- 后续计算改变 `ans` 后，再从旧记录插入，仍使用该条当时的结果。插入本身不新增记录或修改 `ans`。
- 对 `1/0` 的失败记录打开菜单，只提供“复制整条计算”，内容包含原公式与错误说明；
  没有“复制纯数值”或“插入结果数值”，原“修改公式”仍可用。
- 计算 `-0` 后纯数值复制为 `-0`、插入为 `(-0)`；计算 `1e-200*1e-120`，复制的科学计数数值可重新计算。
- 中文组词中不因菜单插入丢失预编辑文字；完成组词后可插入。使用 `@` 补全后再操作记录菜单，输入正常。
- 在第二窗口操作记录，第一窗口草稿与历史保持不变；切回普通文档后编辑命令正常，关闭重开无残留菜单。
- 明暗主题、窄窗口及 100% / 150% / 200% DPI 下，“记录操作”和菜单文字可读、可点击。

- 计算 `sin(0)` 后直接计算 `ans+0.1`，应含近似计算／转换损失；从 `sin(0)` 记录插入数字 0 再计算
  `0+0.1`，应为十进制 0.1、无来源行。原记录和 ans 不因复制／插入动作本身改变；状态提示不保留原计算来源。
- `floor(1/3)` 的零仍有舍入来源；复制并重新提交数字 `0` 后无来源。整条复制和 TXT／Markdown 则包含原来源行。
- 在约 440 像素窄窗口和大字体下检查 50 位数字、`1/3` 和三种来源；数字应完整软换行且可全选复制，
  不裁切、不省略，不把视觉换行带入剪贴板或导出，记录操作仍可点击。

## 历史召回与草稿

- 连续计算 `11`、`1+`、`ans+1` 后在输入区输入 ` 100+ ` 作为草稿，选中其中一段。
  Alt+↑ 依次召回 `ans+1`、`1+`、`11`，最旧处继续按不循环；Alt+↓ 依次向后，
  越过最新记录回到 ` 100+ `，草稿空白、光标与选区完整恢复，记录数量和 `ans` 不变。
- 在本轮浏览中将某条历史公式改写，再浏览其他条目后返回，临时修改仍在；原记录不变。
  返回草稿后重新召回，应重新读取原历史公式；粘贴的多行、中文草稿也能完整恢复。
- 保留草稿并召回 `ans+1`，修改后按 Ctrl+Enter（含小键盘 Enter）或点击“计算”，
  按当前 `ans` 追加一条结果，成功后返回原草稿；普通 Enter 不计算。
- 召回 `1+` 后提交失败，保留输入与错误位置；修正成 `1+2` 后提交得到 3，并回到原草稿。
  空输入、未完成 @ 查询和输入法组词期间的提交不会丢失已保存草稿。
- 点击“再次使用 / 修改公式”也能保存草稿，随后 Alt+↓ 可返回；浏览期间插入结果数值，
  当前编辑可撤销／重做。切换浏览项后撤销栈重置，不用撤销代替 Alt+↓ 返回草稿。
- 普通 ↑↓ 移动多行光标，Shift+方向键选择文字；Alt+Shift 或 Alt+Ctrl 组合不触发召回。
- 打开 `@p` 候选，普通 ↑↓ 选择候选，Alt+↑↓ 不改写公式；Esc 后可召回。
  中文组词时 Alt+↑↓ 不召回、不丢预编辑，文字上屏后可以浏览。
