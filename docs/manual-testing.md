# CalcTabdd 0.1.0 Windows 手动测试

本包是预发布测试版。自动化验证包括 Windows Release 编译、数学计算、界面事件、DLL
加载和真实 QScintilla 控件接入；完整 notepad-- 宿主体验仍需以下手动确认。

## 安装

1. 确认使用 Windows x64 版 notepad--，Qt 运行库为 5.15.2。
2. 退出所有 notepad-- 窗口。将包中 `plugin/calctabdd.dll` 复制到 notepad-- 安装目录的
   `plugin` 子目录。升级时先备份同名 DLL；不要覆盖宿主的 Qt DLL。
3. 启动 notepad--，打开 **插件 → CalcTabdd 计算器 → 打开计算器**。
4. 若未出现菜单，记录宿主完整版本、架构、DLL 放置路径和任何错误提示。

## 功能与界面

- 公式在上、结果在下，底部输入区始终可用；改变窗口大小后布局完整。
- `1+2*3` 应得到 `7`；`(1299+899)*0.85` 应得到 `1868.3`；`sqrt(9)` 应得到 `3`。
- `Ctrl+Enter` 和 `Ctrl+小键盘 Enter` 均提交；普通 Enter 不提交；点击“计算”也可提交。
- 成功后输入清空；`12/(3-3)` 显示除零错误并保留输入；修改后可以继续计算。
- “再次使用 / 修改公式”正确回填原公式；选中结果后能复制。
- 连续输入足够多条记录后滚动到最新结果，也能向上阅读旧记录。
- `ans` 引用上一条成功结果，失败计算不更新 `ans`。

## 宿主行为

- 切到普通文档再切回，记录保留、焦点回到输入区，普通文档内容不变。
- 重复打开计算器会回到现有标签；两个宿主窗口的历史互不影响。
- 计算器激活时测试菜单和快捷键复制、粘贴、剪切、全选、撤销、重做。
- 计算器激活时保存、另存为、查找替换不可用；切回普通文档后恢复。
- 分别测试关闭当前、关闭其他、关闭左/右侧、关闭全部。
- 有其他未保存文档时测试退出、取消退出、再次退出，确认计算器不导致额外空白文件保存提示。
- 关闭计算器后重开应为空历史；退出和重启后不恢复计算记录。
- 启用宿主会话恢复后，确认没有崩溃或文档污染；底层未命名空标签可能按宿主规则恢复，
  不应误认为计算历史恢复。

## 系统体验

- 中文输入法预编辑、候选确认，以及输入后继续计算。
- 明暗主题、100% / 150% / 200% 缩放、跨显示器移动。
