# CalcTabdd v0.2.15 测试版

本版相较 v0.2.14，为独立十进制基础层增加除法及统一舍入规则。
**界面计算、ans、历史、复制、导出与会话仍使用现有 double 规则，尚未启用完整精确十进制计算。**

## 相较 v0.2.14 的变化

- 基础层除法最多保留 50 位有效数字，有限且可表示的商完整保留；循环小数或超过容量的有限商，取最近值，恰好居中时末位取偶数。
- 每次除法完成后只舍入一次，用完整余数判断半值，不经过 double，也不截断余数后重复舍入。
- 除法同时返回本次是否发生有损舍入；仅规范化尾随零不算有损。结果及舍入标志在失败时均保持原值，支持输出与输入为同一对象。
- 除数为正零或负零均报除零错误，包括零除以零。精确商及舍入后均检查规范化指数 -999 至 999，超限报上溢或下溢，不把非零下溢变成零。
- 求商只按最多 50 位的系数缩放，余数临时最多 51 位，不按数值指数差展开长字符串。
- 增加正负半值、半值两侧、完整余数、有限长小数、符号零、范围、输出别名与失败保护回归；475 组独立参考数据由 Python Decimal 与 Fraction 交叉核对后固定保存，Windows 测试直接读取。

## 连续运算规则与交付边界

基础层加减乘仍精确计算，规范化后超过 50 位有效数字则报精度超限。除法后的值也遵守这一规则：

- 基础层 `1/8` 精确得到 `0.125`。
- 基础层 `(1/3)*3` 得到小数点后 50 个 9，不自动改为 1。
- 基础层 `(1/6)*6` 在乘法时需要 51 位有效数字，返回精度超限。

这些是独立数值层的回归预期，不是当前界面输入的验收预期。科学函数混算、近似来源传播、统一文本、历史与会话的十进制接入仍待后续完成。
现有 `round(x)` 继续按最近整数、半整数远离零计算，例如 `round(2.5)=3`、`round(-2.5)=-3`。
自定义公式仍每行一个参数，通过 Ctrl+Enter 或“计算”确认；布局、记录和保存机制保持现有行为。

## 安装与验证

退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 放入宿主 `plugin` 目录，重启后生效。

发布流程执行 Windows x64 Release 编译、计算引擎／Qt 页面／动态插件三组回归，校验 ZIP、源码提交、DLL 架构、导出及依赖。
各组实际结果与构建来源见 `BUILD-INFO.json`。当前界面仍按 `TESTING.md` 的浮点预期检查；真实 Windows 宿主的 DLL 加载、输入法、DPI 和关闭退出由用户手动确认。
