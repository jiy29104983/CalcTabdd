# CalcTabdd 0.2.2 测试版

在 0.2.1 基础上增加计算记录的复制和结果插入，便于可靠复用历史数值。

## 相比 0.2.1 的改进

- 每条记录增加“记录操作”菜单。成功记录可“复制纯数值”“复制整条计算”“插入历史结果”；
  失败记录可复制原公式和错误说明，原有“再次使用 / 修改公式”入口保留。
- 纯数值复制不带 `=`，整条复制包含原公式与下一行结果；数值从当时的内部结果读取，
  使用最多 17 位有效数字的可往返格式，保留负零，支持小数与科学计数法。
  例如 `0.1+0.2` 仍显示 `0.3`，复制纯数值为 `0.30000000000000004`。
- 插入历史结果使用当时的固定值，替换输入框选区或插入光标处，保留外围公式。
  负数自动加括号，使 `(-2)^2` 保持正数结果；支持一次撤销／重做，插入后可继续编辑。
- 复制和插入不更新 `ans`、不自动提交，也不重新计算历史公式。回填原公式后重新提交
  仍按当前会话求值。失败记录不提供成功数值操作。
- 增加浮点边界与随机样本逐位往返、区域设置、真实菜单点击、历史追加后的旧记录操作、
  光标与选区、撤销、补全及预编辑保护、多窗口和原生缓冲区隔离回归。帮助与使用清单同步更新。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的
`plugin` 子目录，重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
插件包不包含 Qt DLL，请勿覆盖宿主运行库。下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与记录模型、页面、动态 DLL 与 QScintilla
三组自动化测试以及包校验通过后发布。包内 `BUILD-INFO.json` 记录提交、流水线和测试数量。
新菜单、剪贴板、撤销、输入法、关闭退出及 DPI 请在完整 Windows 宿主中按包内 `TESTING.md` 复核；
自动化证据不替代实机验收，也不代表全部宿主发布二进制已验证。

本版仍为预发布。内部计算保持 double，界面最多显示 15 位有效数字；可往返格式不提高
原计算精度，手动选中显示文字复制仍可能损失精度。插入不会自动补乘号，计算仍需 Ctrl+Enter
或点击“计算”；关闭标签后清空会话，暂不提供跨启动历史保存。
