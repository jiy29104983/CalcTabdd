# CalcTabdd 0.2.4 测试版

在 0.2.3 基础上增加“清空会话”，可在保留原始草稿的同时重新开始当前窗口的计算。

## 相比 0.2.3 的改进

- 右上角增加“清空会话”。确认后删除全部成功和失败记录，`ans` 重置为 `0`，
  新记录从 `01` 开始；其他宿主窗口的会话保持不变。
- 普通输入中的草稿、光标、选区和文字撤销记录保留。历史浏览中清空会返回召回前的
  原始草稿，并丢弃本轮临时编辑；确认框会明确说明。草稿中的 `ans` 随会话重置为 `0`。
- 确认框默认取消，Enter、Esc 或关闭确认框可取消；点击“清空会话”才执行清空。
  清空记录不可撤销，文字撤销不会恢复计算记录。没有记录或输入法组词期间按钮不可用。
- 确认只阻止当前宿主窗口操作，其他窗口仍可计算；页面隐藏时取消确认，关闭页面时释放确认框。
- 增加模型重置、确认／取消、草稿及反向选区、历史临时编辑清理、菜单销毁、滚动恢复、
  补全／预编辑和多个宿主窗口的自动化回归。帮助、安装说明和使用检查清单同步更新。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的
`plugin` 子目录，重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
插件包不包含 Qt DLL，请勿覆盖宿主运行库。下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与模型、页面、动态 DLL 与 QScintilla 三组自动化测试
及安装包校验通过后发布。包内 `BUILD-INFO.json` 记录提交、流水线和测试数量。
实际宿主中的确认框焦点、中文输入法、多窗口、关闭退出与 DPI 请按 `TESTING.md` 复核，
自动化不替代实机验收。

本版不提供单条记录删除或清空撤销，不增加跨启动保存。清空后仍可继续输入、补全、计算及操作新记录。
原计算算法、显示精度、记录复制／结果插入和历史召回按键保持不变。
