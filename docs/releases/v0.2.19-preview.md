# CalcTabdd v0.2.19 测试版

本版相较 v0.2.18，改进自定义公式的输入与修改流程：在页面内直接编辑公式，按 Enter 应用，并支持 @ 快捷补全。

## 相较 v0.2.18 的变化

- 自定义公式原预览栏改为可编辑的公式定义栏。首次输入和后续修改都在该栏完成，不再打开定义弹窗。
- 选择“自定义公式模式”，输入 `A=x+y` 后按 Enter，自动生成参数行；同名参数保留值，新增参数留空。
- 定义栏支持与普通公式输入相同的 17 个函数／常量补全，以及中文关键词、方向键、Enter／Tab、鼠标选择和撤销重做。
  例如 `A=@sq` 补全为 `A=sqrt()`；候选打开时 Enter 只插入候选，填写参数名后再次 Enter 才应用定义。
- 未确认或无效的修改不会替换已确认公式，也不会继续使用旧公式计算。Esc 还原已确认定义，首次定义时取消则回到普通模式。
- 参数继续每行一个；Enter 换行，Ctrl+Enter 或“计算”新增记录。应用定义本身不产生计算记录，也不改变 ans。
- 本地会话继续保存已确认的公式；定义栏未确认的修改只在当前窗口保留，关闭后恢复的是最后确认的定义。会话格式和数值规则保持不变。
- 更新帮助、安装说明和使用检查清单，补充直接编辑、补全确认、输入法保护、宿主编辑菜单及关闭切换回归。

## 安装与验证

退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 替换到宿主 `plugin` 目录，重启后在“关于 CalcTabdd”确认 **0.2.19**。
目标为 Windows x64、Qt 5.15.2、MSVC v142；不要覆盖宿主 Qt DLL。

发布流程执行计算引擎、Qt 页面与动态插件三组 Windows Release 回归，并校验安装包；计数见 `BUILD-INFO.json`。
真实 notepad-- 的输入法、Enter／补全交互、主题、DPI 与关闭退出仍须按 `TESTING.md` 单独确认。
