# CalcTabdd v1.0.4 测试版

本次开放程序员模式的计算与结果界面，支持固定位宽整数、位运算和多进制查看。
普通／自定义计算保留既有数学规则。

## 本次变化

- 增加“程序员”模式入口，以及 8／16／32／64 位、有符号／无符号控件，默认 32 位无符号。
- 记录显示提交时配置、完整十进制结果和 HEX；展开进制详情查看 BIN／OCT，旧结果不随当前配置改变。
- 展示固定宽度回绕来源和错误位置，64 位整数全程不经过浮点转换。
- 程序员 `^` 为异或，普通／自定义 `^` 继续为乘方；帮助与 `@` 候选随模式切换。
- 支持 Ctrl+Enter／计算按钮提交、Enter 不换行、中文位运算模板、键盘回填与当前窗口内的草稿保护。
- 模式及设置在窄窗口自动换行，长二进制结果可换行查看；高度不足时可滚动输入区到计算按钮。

## 当前使用范围

程序员记录仅在当前窗口保留，关闭标签后不保留。可选中文字复制；
各进制专用复制菜单、结果插入、含程序员记录的导出以及程序员会话保存尚未开放。
已开启数学会话保存时，须先停止保存再进入程序员；使用程序员后请在新空白计算器中保存或恢复数学会话。
现有 version 3 数学会话文件保持原样。

## 安装与验证

下载对应 Windows x64 ZIP 和 `.sha256` 文件，退出 notepad-- 后替换 `plugin/calctabdd.dll`。
重启后在“关于 CalcTabdd”确认版本 **1.0.4**。目标工具链为 Qt 5.15.2 / MSVC v142。

测试包由 Windows Release 引擎、页面、动态插件测试、Debug 页面测试及包校验通过后生成。
具体提交与测试结果见 `BUILD-INFO.json`。真实 Windows 宿主的输入法、DPI、加载和关闭退出
仍需按包内 `TESTING.md` 检查。
