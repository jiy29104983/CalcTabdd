# CalcTabdd 0.2.0 测试版

在 0.1.0 基础上新增可搜索帮助、`@` 快捷补全与插件关于信息，计算算法和精度策略保持不变。

## 相比 0.1.0 的改进

- 计算器右上角新增“帮助”，插件菜单中的“运算与精度帮助”打开同一个非模态窗口。
  支持英文名称与中文关键词搜索，完整列出运算符、14 个函数、pi/e/ans、语法和精度限制。
- 输入 `@` 查找函数和常量，继续输入英文前缀或中文关键词筛选；候选显示参数、中文说明和示例。
  ↑↓ 选择，Enter/Tab 插入，Esc 关闭，鼠标也可选择；普通 `/` 仍为除号。
- 函数补全插入括号并定位参数输入位置；二元函数插入逗号，已有括号及参数会保留。
  替换只作用于当前 `@` 查询，保留前后公式，支持撤销／重做。
- Ctrl+Enter 或计算按钮遇到未完成的 `@` 查询时给出提示，不提交错误记录、不更新 ans。
  中文输入法组词期间不接管候选确认；文字上屏后再匹配。
- 插件下拉菜单新增“关于 CalcTabdd”，显示插件版本、目标架构与运行库、notepad-- 源码兼容参考和实机验证边界。
- README 和内置帮助说明运算语法与精度限制；帮助与补全共用运算清单。

## 安装与兼容性

退出 notepad--，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的 `plugin` 子目录，
重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原有同名 DLL。

编译目标：Windows x64、Qt 5.15.2、MSVC v142。宿主公开源码基线为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
源码接口参考不等于两个版本的发布二进制都已实机验收；其他宿主版本未验证。
请勿覆盖宿主 Qt DLL。下载后用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

此测试包只在 Windows Release 编译、三组自动化测试及包校验全部通过后发布。
包内 `BUILD-INFO.json` 记录测试组、通过数量、源码提交和流水线编号。
新增测试覆盖补全筛选、中文关键词、输入法事件、插入位置、键盘与鼠标选择、取消、
撤销／重做、帮助搜索、关于版本一致性和真实 QScintilla 底层文档隔离。

请按包内 `TESTING.md` 确认插件加载、菜单、关闭退出、输入法、主题与 DPI 在当前宿主中的表现。

内部仍使用双精度实数计算，最多显示 15 位有效数字；没有新增数学函数或任意精度支持。
历史仅保留在当前标签，关闭或退出后清空。本版为预发布测试版。
