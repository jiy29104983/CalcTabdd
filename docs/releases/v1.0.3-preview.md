# CalcTabdd v1.0.3 测试版

本次加入程序员整数计算核心及边界回归，为后续程序员模式做准备。
**当前界面仍提供普通计算和自定义公式，程序员模式入口尚未开放。**

## 本次变化

- 整数核心支持 8、16、32、64 位的有符号／无符号计算、十进制及带前缀的二／八／十六进制输入。
- 覆盖整数四则、取余、位运算、固定宽度回绕来源，以及移位、除零、输入范围和表达式长度限制。
- 使用独立的任意精度整数参考数据和完整 8 位双操作数回归验证极值；64 位整数计算全程不经浮点转换。

这些能力目前仅在独立核心中提供。普通／自定义的 `^` 仍表示乘方，`ans`、历史、复制、
导出及 version 3 会话继续沿用现有规则。新整数规则尚未接入界面、历史和会话。

## 安装与验证

下载对应测试版的 Windows x64 ZIP 和同名 `.sha256` 文件，退出 notepad-- 后替换 `plugin/calctabdd.dll`。
重启后在“关于 CalcTabdd”确认版本 **1.0.3**。目标工具链为 Qt 5.15.2 / MSVC v142。

测试包在 Windows Release 引擎、页面、动态插件测试，Debug 页面测试和包校验通过后生成。
`BUILD-INFO.json` 记录具体提交与测试结果。真实 Windows notepad-- 的加载、输入法、
DPI 和关闭退出仍需按包内 `TESTING.md` 检查。
