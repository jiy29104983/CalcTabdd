# CalcTabdd v1.0.0

CalcTabdd 首个正式版本，为 notepad-- 提供独立的计算器标签页。公式与结果上下分行，支持连续计算、自定义公式、记录复用和本地会话。

## 相较 v0.2.20 测试版

- 发布 v1.0.0 正式版本，统一插件版本、关于窗口、安装说明和使用检查清单，移除关于窗口中的“测试版”标记。
- 重写项目首页，补充普通计算和自定义公式的真实界面截图、快速上手示例、快捷键、开发与贡献说明。
- 建立正式版本标签发布流程，提供 Windows x64 安装包、中文变更说明和 SHA256 校验文件。
- 计算规则、输入交互和第 3 版会话格式与 v0.2.20 保持一致。

## 首个正式版本包含

- 连续记录：公式在上、结果在下，Ctrl+Enter 或“计算”提交，失败后保留输入和上次成功结果 `ans`。
- 十进制与科学计算：最多 50 位十进制有效数字，四则运算、取余、乘方、14 个函数，以及 `pi`、`e`、`ans`。舍入、近似计算和转换损失单独提示。
- 自定义公式：在页面内定义公式，Enter 应用，每行填写一个参数；普通和自定义模式分别保留草稿。
- 快捷输入：`@` 按英文名称或中文关键词补全，Alt+↑ / Alt+↓ 浏览历史；支持重新使用公式、复制计算和插入结果。
- 保存与分享：导出 TXT / Markdown；可选本地 `.calctabdd` 会话保存与恢复，保留记录、草稿、参数和计算来源。
- 编辑器集成：每个宿主窗口独立计算，支持明暗主题、可搜索帮助，以及普通模式的错误位置提示。

## 安装与升级

1. 下载本页 Windows x64 ZIP 安装包和对应 `.sha256` 文件。
2. 退出所有 notepad-- 窗口，将 `plugin/calctabdd.dll` 复制到宿主安装目录的 `plugin` 文件夹。升级时替换同名 DLL。
3. 重启，选择“插件 → CalcTabdd 计算器 → 打开计算器”，在“关于 CalcTabdd”确认版本 **1.0.0**。

目标环境为 **Windows x64、Qt 5.15.2、MSVC v142**。请勿覆盖宿主的 Qt DLL。可在 PowerShell 使用 `Get-FileHash <ZIP路径> -Algorithm SHA256` 与校验文件核对。

## 使用说明

- 本地保存默认关闭。需要关闭后继续计算时，请先通过“本地会话”开启保存；之后在空白计算器中恢复。
- 会话继续使用第 3 版格式，支持 v0.2.20 保存的同格式文件；旧格式不迁移。TXT / Markdown 导出文件不能作为会话恢复。
- 十进制结果最多 50 位有效数字；每次除法按最近值、半值取偶舍入。科学函数使用近似计算，最多显示 17 位不代表每一位都准确。
- 纯数值复制或插入后再次提交按新十进制输入处理；使用 `ans` 或会话恢复可以保留原结果的类型和计算来源。
