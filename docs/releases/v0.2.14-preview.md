# CalcTabdd v0.2.14 测试版

本版相较 v0.2.13 增加十进制数值基础层与边界回归，并提前限制自定义参数展开长度。
**精确十进制基础层尚未接入用户计算入口；界面、ans、历史、复制、导出与会话仍使用现有 double 规则。**

## 相较 v0.2.13 的变化

- 新增从原始文本直接解析的十进制数值类型，系数规范化后最多 50 位，规范化科学计数指数限定为 -999 至 999。
- 基础层支持精确加、减、乘；逐次运算检查容量与范围，超限返回明确错误，不静默舍入，不把非零下溢变成 0。
- 规范化后再判断精度，支持进位与尾随零消除；运算失败保留输出原值。临时运算存储有界，不按巨大输入指数分配内存。
- 新增有效位数、指数、语法、长输入、符号、输出别名、边界消去与超限回归；与独立整数参考和十进制参考数据对照。
- 自定义公式先计算参数展开后的长度，超出 4096 个 UTF-16 代码单元时立即提示；不新增记录，不改变上次成功结果。

## 本次交付边界

此版交付数值基础层及展开保护。除法舍入、数学函数混算、统一数值显示和会话接入尚未完成，
不能以本版基础层测试通过推断整个计算器已经支持精确十进制。
例如当前界面中的 `0.1+0.2` 仍显示 `0.3`，复制纯数值仍为 `0.30000000000000004`。

现有自定义模式、上下分行界面、历史与会话继续使用。计算仍通过 Ctrl+Enter 或“计算”确认，参数每行一个。

## 安装与验证

退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 放入宿主 `plugin` 目录，重启后生效。

发布流程执行 Windows x64 Release 构建、计算引擎／Qt 页面／动态插件三组测试，并校验 ZIP、源码提交、
DLL 架构、插件导出与依赖；具体结果见 `BUILD-INFO.json`。
真实 Windows 宿主的 DLL 加载、输入法、DPI、关闭退出及展开错误提示仍需按 `TESTING.md` 手动确认。
