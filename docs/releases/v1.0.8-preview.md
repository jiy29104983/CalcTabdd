# CalcTabdd v1.0.8 测试版

本次完善程序员模式帮助、补全说明和三模式完整流程验证。

## 本次变化

- 帮助窗口按模式显示搜索提示、页签和无匹配提示。程序员帮助集中提供整数、位运算、
  进制、回绕和会话操作，普通／自定义继续提供数学函数与精度说明。
- 补充无符号取负、有符号最小值除法及余数、数字分隔符规则。
  例如 8 位无符号 `-1=255` 且提示回绕；8 位有符号 `-128/-1=-128` 且提示回绕，
  `-128%-1=0` 不新增回绕。
- 程序员帮助增加会话文件保护说明：空白页恢复、同文件独占、完整校验、
  文件大小和记录条数上限，以及保存失败时重试或另存的处理方式。
- 安装说明列出全部 8 种程序员补全模板；使用清单补充帮助检索和完整混合流程。
  补全只插入模板，完成操作数后仍须 Ctrl+Enter 或点击“计算”提交。
- 增加全部程序员补全的实际计算、明暗帮助检索，以及帮助到三模式计算、
  混合导出、保存恢复和继续计算的组合回归。

## 使用与会话

普通／自定义的 `^` 为乘方，程序员的 `^` 为异或。数学与整数 `ans` 分开，
三种模式分别保留草稿；复制／插入纯数值按新输入处理，完整记录和会话保留原来源。

会话仍只读写 **version 4**。version 3 及更早文件不能直接恢复，不提供迁移；
拒绝时保持原文件和当前页面不变。恢复从新的空白计算器手动进行，不重新计算历史。
本次不改变既有运算、复制插入、导出和会话格式。

## 安装与验证

下载对应 Windows x64 ZIP 和 `.sha256`，退出所有 notepad-- 窗口后替换
`plugin/calctabdd.dll`，重启后在“关于 CalcTabdd”确认版本 **1.0.8**。
目标工具链为 Qt 5.15.2 / MSVC v142。

测试包在 Windows Release 引擎、页面、动态插件回归、Debug 页面回归及包校验
通过后生成。提交和测试结果见 `BUILD-INFO.json`。真实 Windows 宿主的加载、
中文输入法、DPI、跨窗口操作和完整关闭／退出／恢复，仍须按包内 `TESTING.md` 验收。
