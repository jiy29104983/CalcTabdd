# CalcTabdd v1.0.1

本版本修复公式补全、粘贴目标与宿主操作隔离问题，保持十进制计算规则和第 3 版会话格式。

## 修复与改进

- 修复会话保存、恢复和记录导出窗口的“取消”按钮显示为英文的问题。
- 修复应用自定义公式、替换输入内容时，补全逻辑读取无效光标位置的问题；禁用或隐藏补全时不再解析文本。
- 修复选中历史公式／结果后粘贴时，焦点在定义栏、内容却写入参数区或隐藏草稿的问题。尚未应用的定义正在编辑时，粘贴明确写入定义栏。
- 补齐宿主主工具栏操作隔离：复制、剪切、粘贴、撤销和重做作用于计算器；文档保存、全部保存、自动保存、查找、替换和标记入口在计算器标签中不可用。切回普通文档恢复原有工具栏及其状态。
- 为计算器标签提供专属右键菜单，保留正常关闭入口，避免宿主“另存为”误保存空白底层文档。保存计算会话或分享记录请使用页面内“本地会话”或“导出记录”。普通文档的右键菜单保持原有功能。
- 统一 Enter 的帮助与使用说明：普通模式不提交、不换行；自定义参数区换行；公式定义栏应用定义。Ctrl+Enter 仍用于明确提交计算。
- 增加粘贴、补全重置、工具栏恢复、多窗口及标签菜单回归，并在 Windows 发布前运行启用断言的 Debug 页面测试。

## 安装与升级

1. 下载 Windows x64 ZIP 和同名 `.sha256` 校验文件。
2. 退出全部 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 放入宿主的 `plugin` 目录，替换旧 DLL。
3. 重启后在“关于 CalcTabdd”确认版本 **1.0.1**。

目标环境为 **Windows x64 / Qt 5.15.2 / MSVC v142**，无需覆盖宿主 Qt DLL。可使用 PowerShell 的 `Get-FileHash <ZIP路径> -Algorithm SHA256` 核对校验值。

本地保存默认关闭；需要关闭后继续计算时，请先开启保存。继续支持 v1.0.0 的第 3 版会话文件，不迁移更旧格式。
