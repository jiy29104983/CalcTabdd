# CalcTabdd v1.0.2 测试版

本次更新重整计算器界面，保留现有十进制计算规则、明确提交方式和第 3 版会话格式。

## 界面与交互

- 计算记录采用卡片布局，公式在上、结果在下；自定义记录显示定义和参数摘要，错误记录显示修正提示。
- 普通计算和自定义公式通过分段按钮切换；定义栏新增“应用公式”按钮与应用状态提示。
- 页首显示上次成功结果 `ans`，输入区显示历史浏览状态；长摘要根据宽度省略显示，悬停可查看全文。
- 补全候选分层显示函数、分类与示例，帮助内容按类别组织，并随页面主题更新。
- 修正窄窗口、大字体及历史浏览时的按钮挤压和记录操作裁切。高度不足时，底部输入区可以滚动，避免编辑器和提示重叠。
- 长数字公式与自定义记录摘要支持完整换行、文本选择和复制。
- 模式与应用按钮支持 Tab／Shift+Tab 聚焦、空格操作；输入后 Tab 仍先到“计算”。

## 安装与验证

下载对应测试版的 Windows x64 ZIP 和同名 `.sha256` 文件，退出 notepad-- 后替换 `plugin/calctabdd.dll`。
重启后在“关于 CalcTabdd”确认版本 **1.0.2**。目标工具链为 Qt 5.15.2 / MSVC v142。

本测试包由 Windows Release 引擎、页面、动态插件测试，Debug 页面测试和包校验通过后生成。
`BUILD-INFO.json` 记录具体提交与测试结果。真实 Windows notepad-- 的 DLL 加载、输入法、DPI 和关闭退出仍需按包内 `TESTING.md` 检查。
