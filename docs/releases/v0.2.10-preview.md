# CalcTabdd v0.2.10 测试版

本版相较 v0.2.9 撤回文档选区查看功能，继续提供标签页计算器及既有历史、导出和会话保存能力。

## 相较 v0.2.9 的变化

- 移除插件菜单中的“查看文档选区（只读）”及其预览窗口。
- 移除配套的宿主选区读取适配、接口探针、专用测试和流水线步骤。
- 插件菜单保留“打开计算器”“运算与精度帮助”“关于 CalcTabdd”。
- 清理安装说明和使用检查清单中的选区预览操作。
- 现有计算、复制粘贴、历史召回、结果操作、TXT／Markdown 导出和本地会话保存恢复继续保留。

需要计算文档中的公式时，复制公式，切换到计算器底部输入框粘贴，再按 **Ctrl+Enter**。

## 安装与升级

退出所有 notepad-- 窗口，将本包 `plugin/calctabdd.dll` 替换到宿主 `plugin` 目录，重启后生效。
升级不需要删除已保存的 `.calctabdd` 会话文件；会话格式仍为 v1。
不要覆盖宿主的 Qt 或编辑库 DLL。

## 验证范围

发布流程执行计算引擎、页面和动态插件三组自动化回归，并校验安装包的 SHA256、源码提交、
Windows x64 架构和插件导出入口。具体结果记录在包内 `BUILD-INFO.json`。

选区预览已移除，无需再执行其专项手动验收。自动化结果不代表本次安装包在所有真实宿主环境中都已手动测试。
