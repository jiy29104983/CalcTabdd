# CalcTabdd v1.0.9

本版本正式提供程序员整数计算，并完善三种模式的记录复用、会话保存与帮助。

## 程序员计算

- 提供 8／16／32／64 位、有符号／无符号整数，默认 32 位无符号。
  支持十进制及 `0x`、`0b`、`0o` 前缀，完整保留 64 位整数。
- 支持整数四则、余数、与／或／异或／取反和三种移位。
  程序员 `^` 表示异或，普通／自定义的 `^` 继续表示乘方。
- 输入越界报错，运算逐步按位宽回绕并记录来源；整数除法向零截断，
  有符号右移与始终补零的逻辑右移分别提供。
- 默认查看 DEC／HEX，展开详情可查看 BIN／OCT。
  每条记录保留原配置，改变当前设置不会重算或改写旧结果。

## 历史、复用与保存

- 数学与整数 `ans` 独立，三种模式分别保留草稿、光标和选区，程序员模式另保留位宽与符号。
  历史回填恢复原模式与配置，重新提交使用当前对应的 `ans`。
- 支持 DEC／HEX／BIN／OCT 复制、跨模式插入，以及包含原配置和四进制结果的混合 TXT／Markdown 导出。
  插入程序员前检查保存值本身是范围内整数，纯文本重新输入不继承原计算来源。
- 三种模式共用本地会话保存入口，完整保留混合记录、两类 `ans`、三份草稿与浏览状态。
  恢复使用保存值，不重新计算历史；保留文件独占、完整校验、原子写入与失败重试／另存保护。
- 帮助按模式提供搜索提示、整数／数学规则和范围说明；程序员提供 8 种中文补全模板。
  Ctrl+Enter 或“计算”显式提交，补全和输入法组合态优先处理。

## 会话格式与升级

当前只读写 **version 4** 会话。**version 3 及更早文件不能直接恢复，不提供迁移**；
拒绝时保持原文件和当前页面不变。文件格式版本与插件版本分别编号。

保存默认关闭。需要关闭后继续计算时，请先开启保存；重开后从新的空白计算器手动恢复。
TXT／Markdown 导出供阅读和分享，不能用作会话恢复文件。

## 安装

1. 下载 Windows x64 ZIP 和同名 `.sha256` 校验文件。
2. 退出所有 notepad-- 窗口，将 `plugin/calctabdd.dll` 放入宿主的 `plugin` 目录并替换旧 DLL。
3. 重启，在“关于 CalcTabdd”确认版本 **1.0.9**。

目标运行库为 **Qt 5.15.2 / MSVC v142**，无需覆盖宿主的 Qt DLL。
可用 PowerShell 的 `Get-FileHash <ZIP路径> -Algorithm SHA256` 核对校验值。
