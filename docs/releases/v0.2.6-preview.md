# CalcTabdd 0.2.6 测试版

在 0.2.5 基础上增加 TXT／Markdown 计算记录导出，方便留存和分享当前窗口的计算过程。

## 相比 0.2.5 的改进

- 右上角新增“导出记录”，可选择 TXT 或 Markdown，并通过文件选择框指定位置和文件名。
  没有填写后缀时自动补 `.txt` 或 `.md`；覆盖已有文件前再次确认，默认取消。
- 按记录顺序导出原公式、当时的成功结果或错误说明。含 `ans` 的旧公式不重算，
  未提交草稿与历史公式的临时编辑不进入文件。
- 结果采用与整条复制一致的可往返数值，最多 17 位有效数字并保留负零。
  例如 `0.1+0.2` 导出为 `0.30000000000000004`，显示仍为 `0.3`。
- 两种文件均使用 UTF-8（无 BOM）和 LF 换行；Markdown 使用分节与代码块保留多行、中文、
  emoji、反引号、HTML 等原始文字，避免公式或错误信息变成 Markdown 格式。
- 文件完整写入并提交后才替换目标；失败会显示原因，当前记录继续保留，可重试或另选位置。
  导出、取消与失败均保留 `ans`、草稿、选区、撤销记录和历史浏览状态。
- 导出对话框仅限制所属窗口；其他窗口仍可计算。页面隐藏、标签关闭或窗口销毁时取消未完成操作。
  空会话和输入法组词期间不启动导出，只有错误记录时仍可导出。
- 增加导出格式、数值往返、Unicode 与围栏、文件失败、覆盖确认、输入状态保护、多窗口和
  动态插件生命周期回归，并检查明暗主题与窄窗口下的界面。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的
`plugin` 子目录，重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
插件包不包含 Qt DLL，请勿覆盖宿主运行库。下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与模型、页面、动态 DLL 与 QScintilla 三组自动化测试
及安装包校验通过后发布。包内 `BUILD-INFO.json` 记录提交、流水线和测试数量。
实际宿主中的导出位置选择、中文文件名、覆盖确认、失败提示、输入法、主题、DPI 和关闭退出
请按 `TESTING.md` 复核，自动化不替代实机验收。

导出文件用于阅读和留存；本版不增加跨启动历史保存或 TXT／Markdown 导入恢复。
内部仍为 double，数值导出不会提高原计算精度；宿主的保存／另存为命令仍不作为计算记录导出入口。
