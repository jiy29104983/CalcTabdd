# CalcTabdd 0.2.8 测试版

在 0.2.7 基础上增加普通文档选区的只读查看，便于核对所选文本及来源。

## 相比 0.2.7 的改进

- 插件菜单新增“查看文档选区（只读）”。选中文字后可查看来源标签、文本快照、UTF-16 长度与
  CRLF／LF／CR 换行数量；中文前缀、emoji、正反向及跨行选区均纳入回归。
- 支持普通只读文档；无选区时给出提示。查看时不修改源文档、选择范围、修改标记、撤销记录或剪贴板，
  不创建计算器标签、不追加计算记录，也不改变已有计算器草稿。
- 每次按命令所属窗口的当前标签读取，多个窗口互不串用。切换标签、关闭源标签或窗口时关闭查看窗口，
  重新打开会读取当前选区。
- 增加真实 QScintilla、动态插件菜单、不变性、窗口生命周期与明暗主题回归；插件保持只依赖 Qt，
  安装包不增加 QScintilla DLL。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的 `plugin` 子目录，
重启后在普通文档中选中文字，选择“插件 → CalcTabdd 计算器 → 查看文档选区（只读）”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
插件包不包含 Qt DLL，请勿覆盖宿主运行库。下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与模型、页面、动态 DLL 与 QScintilla 三组自动化测试及安装包
校验通过后发布。`BUILD-INFO.json` 记录提交、流水线和测试数量。真实宿主的普通／只读文档、选区、
多窗口、完整关闭退出、主题和 DPI 请按 `TESTING.md` 复核，自动化不替代实机验收。

此入口只展示打开时的快照，不自动刷新、计算、复制、跳回源位置或写回结果。计算器、二进制及分页大文件
标签不支持。预览将换行显示为分行，原换行类型由计数区反映。

内容遵循宿主返回规则：NUL 字符会变为空格；列选区按行合并，多选区可能直接拼接。此接口不提供原始字节、
各子选区范围或精确源位置，不能用于无损字节提取。宿主源码参考不等于所有发布二进制已经验证兼容。
