# CalcTabdd 0.2.8 测试版

在 0.2.7 基础上完善宿主接口兼容性验证；计算器的使用方式与保存恢复功能保持不变。

## 相比 0.2.7 的改进

- 增加独立进程中的宿主选区接口探针，覆盖中文／emoji 前缀、跨行、无选区与只读文档，
  区分可读取结果、接口缓存缺失和 Windows x64 访问冲突，避免在用户宿主进程中调用未经验证的通路。
- 固定宿主源码的 Qt 输入法选区查询在 Windows x64 存在指针截断风险；另一无障碍接口在首次读取
  已有选区时可能返回空。当前版本不提供文档选区查看或自动计算入口，避免错误读取或宿主崩溃。
- 修正 Linux 从固定宿主源码构建测试依赖时缺失的整数类型头文件，仅调整测试构建参数，不修改宿主源码。
- 保留原有计算引擎、记录操作、历史召回、导出、本地保存恢复及动态 DLL 集成回归。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的 `plugin` 子目录，
重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
插件包不包含 Qt DLL，请勿覆盖宿主运行库。下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与模型、页面、动态 DLL 与 QScintilla 三组自动化测试及安装包
校验通过后发布。`BUILD-INFO.json` 记录提交、流水线和测试数量。探针作为测试辅助程序在独立子进程中
运行，不进入安装包；探针通过表示观察到并正确识别预期的接口行为，包括不安全接口的失败，
不代表文档选区读取已经可用或通过真实宿主验收。

真实 notepad-- 的 DLL 加载、菜单、完整关闭退出、输入法、主题和 DPI 仍按 `TESTING.md` 复核。
现有计算能力、可选本地保存与恢复规则沿用 0.2.7，宿主接口限制未通过修改共享宿主或临时剪贴板替换来绕过。
