# CalcTabdd v0.2.11 测试版

本版相较 v0.2.10 新增自定义公式模式：定义一次公式，填写不同参数，确认后逐条记录结果。

## 相较 v0.2.10 的变化

- 底部模式菜单提供“定义／修改公式”与普通／自定义模式切换。每个窗口维护一个当前公式，支持多个参数。
- 定义 `A=x+y` 后自动生成 `x=`、`y=` 分行输入，也可填写 `x=1 y=2`。参数支持有符号数字、小数、科学计数法。
- 填写过程不计算、不预览；Ctrl+Enter 或“计算”才新增历史，显示 `A=1+2`，下一行 `= 3`。成功后参数保留。
- 公式支持全部现有运算、14 个函数、嵌套、pi/e/ans。名称区分大小写；负数代入保留必要括号。
- 两种模式分别保留草稿，共享当前窗口的 ans。修改定义保留同名参数；历史复用恢复原定义与当时参数，旧记录不变。
- 非法或缺少参数先提示修正；数学求值错误继续记录错误条目，失败不更新 ans。复制与导出包含名称、代入式和结果。
- 本地保存统一保留当前模式、两份草稿、定义、参数、历史与浏览状态，恢复不重新计算历史结果。

## 快速使用

底部“普通计算”菜单 → “定义／修改公式…” → 输入 `A=x+y` → “使用公式”。
填写 `x=1`、`y=2`，按 Ctrl+Enter 得到 3。改变参数后再次确认，即新增一条历史。
同一菜单可切回普通计算，恢复原草稿。自定义参数区 Enter 换行，Ctrl+Enter 计算。

## 安装与会话兼容

退出所有 notepad-- 窗口，将 `plugin/calctabdd.dll` 替换到宿主的 `plugin` 目录，重启后生效。
不要覆盖宿主的 Qt 或编辑库 DLL。默认仍不保存会话；需要跨关闭保留时主动开启“本地会话”。

本版兼容读取旧 v1 会话，后续保存写入 v2。0.2.10 及更早插件不能读取 v2；需要回退时请使用升级前的文件备份。
未知版本或损坏文件不覆盖。保存失败时保留内存内容，可重试或另存新文件。

## 验证范围

发布流程执行计算引擎、Qt 页面及动态插件三组自动化测试，并校验 ZIP 的 SHA256、提交、Windows x64 架构和插件导出。
测试覆盖全部现有函数、参数语法与优先级、混合历史、草稿保护、v1/v2 保存恢复及多窗口生命周期。
实际构建与测试结果记录在包内 `BUILD-INFO.json`。
