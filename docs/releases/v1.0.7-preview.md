# CalcTabdd v1.0.7 测试版

本次开放程序员与混合会话的本地保存和恢复。

## 本次变化

- 普通、自定义和程序员模式共用本地保存入口。开启保存后可以自由切换模式，
  混合记录、两类 `ans`、三份草稿、光标、选区和程序员设置一起保存。
- 程序员结果保存原始位模式、位宽、符号和回绕来源。
  `18446744073709551615` 等 64 位整数完整往返，结果由保存值恢复，不重新计算历史。
- 历史浏览中的位置、原草稿和各条临时编辑一起恢复；再次提交继续使用当前对应的 `ans`，
  追加新记录。当前设置与整数 `ans` 的原设置分别保留，引用时仍检查数值范围。
- 保留文件独占、原子写入、外部修改检测、保存失败重试和另存保护。
  保存默认关闭，恢复仍须从新的空白计算器手动选择文件。
- 同步模式提示、可搜索帮助、安装说明和使用检查清单。

## 会话格式变化

本版只读写 **version 4** 会话文件。**version 3 及更早文件不能直接恢复，
不提供兼容或迁移**；拒绝时保持原文件和当前页面不变。
格式版本与插件版本分别编号。

三种模式均保留数学数值及来源、整数位模式及回绕来源。尚未应用的公式定义、
输入法未上屏候选和文字撤销栈不保存。单文件仍限 16 MiB、10000 条记录，
文件须整份校验通过后才恢复。

TXT／Markdown 导出供阅读和留存，不能作为会话文件恢复。

## 安装与验证

下载对应 Windows x64 ZIP 和 `.sha256` 文件，退出 notepad-- 后替换
`plugin/calctabdd.dll`，重启后在“关于 CalcTabdd”确认版本 **1.0.7**。
目标工具链为 Qt 5.15.2 / MSVC v142。

测试包在 Windows Release 引擎、页面、动态插件回归、Debug 页面回归及包校验
通过后生成。提交和测试结果见 `BUILD-INFO.json`。真实 Windows 宿主的加载、
输入法、DPI、关闭退出与重新打开后恢复仍需按包内 `TESTING.md` 检查。
