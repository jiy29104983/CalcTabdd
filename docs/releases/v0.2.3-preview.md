# CalcTabdd 0.2.3 测试版

在 0.2.2 基础上增加键盘召回历史公式，并保留召回前未提交的草稿。

## 相比 0.2.2 的改进

- 在输入框按 Alt+↑ 从最新记录向前浏览，Alt+↓ 向后浏览，越过最新记录返回草稿。
  成功和失败记录均可召回，最旧处不循环；普通方向键保持光标移动和文字选择行为。
- 首次召回保存完整草稿、光标和选区，包括空白、多行及中文内容。浏览期间保留每条公式
  的临时编辑，原计算记录保持不变；返回草稿或成功提交后结束本轮浏览。
- 召回后按 Ctrl+Enter 或点击“计算”才追加计算，仍使用当前会话的 `ans`。
  成功后返回原草稿；失败保留输入和错误位置供修正。“再次使用 / 修改公式”也保留草稿。
- 输入法组词或 @ 候选打开时不召回，补全的方向键、确认和取消规则不变。
  历史快捷键仅作用于计算器输入区；切回普通文档后保留宿主原快捷键。
- 增加草稿和反向选区往返、临时编辑、错误修正、成功提交、候选／预编辑优先、
  宿主快捷键冲突、多窗口切换及关闭重开回归；帮助、底部提示和使用检查清单同步更新。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的
`plugin` 子目录，重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
插件包不包含 Qt DLL，请勿覆盖宿主运行库。下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与模型、页面、动态 DLL 与 QScintilla 三组自动化测试
及安装包校验通过后发布。包内 `BUILD-INFO.json` 记录提交、流水线和测试数量。
实际宿主的召回按键、中文输入法、关闭退出和 DPI 请按 `TESTING.md` 复核，自动化不替代实机验收。

切换浏览项会重置输入框的撤销栈，当前项的文字编辑和结果插入仍可撤销／重做。
草稿与临时编辑只在当前标签保存；关闭标签或退出后清空，不提供跨启动恢复。
内部计算、显示精度、记录复制／结果插入和普通 Enter 不提交的规则保持不变。
