# CalcTabdd v0.2.16 测试版

本版相较 v0.2.15，增加有界十进制与 binary64 近似数值的混算基础层，并提供共用解析器和自定义公式的内部数值求值接口。
**界面计算、历史中的 ans、复制、导出与会话文件仍使用现有 double 规则；完整精确十进制用户流程尚未启用。**

## 相较 v0.2.15 的变化

- 新增精确十进制比较、取余、取整、整数乘方和有限精确平方根，沿用 50 位规范化有效数字及规范化指数 -999 至 999 的边界。
- 取余直接计算精确余数，不使用舍入除法再乘回；非零余数与被除数同号，可处理 `0.3%0.1=0` 和 `1e999%3=1`。
- `abs`、`min`、`max`、`floor`、`ceil`、`round` 对十进制操作数不经过 double；`round` 的半整数仍远离零。
- `sqrt` 优先判断有限精确平方根，例如 `sqrt(0.09)=0.3`、`sqrt(1e400)=1e200`；其余平方根使用近似路径。
- 三角、对数、指数、非整数乘方及 pi/e 使用 binary64，并保留近似来源。每个节点分别决定数值路径，不把整条表达式提前转为 double。
- 分别记录十进制除法有损舍入、近似计算路径和实际转换损失；取整、乘零、相消及 min/max 选取结果都保留上游来源。转换损失按精确数值比较，不能靠打印字符串判断。
- 普通与自定义公式内部接口共用原解析器，保留优先级、语法限制及 UTF-16 错误定位。内部 ans 可保留数值类型和来源；计算失败不修改传入值，自定义参数按十进制校验并保留原始字面量。
- 新数值层在 Windows 使用严格浮点环境设置，明确保留 min/max 相等参数的左值和负零；保存恢复调用方浮点状态。
- 新增独立 Decimal／Fraction／整数开方参考数据、binary64 位模式转换检查，以及数值类型、来源传播、输出别名、失败保护、浮点环境和两种公式入口的一致性回归。

## 数值核心的限制

- 十进制整数幂的指数绝对值最多 10000，超出报资源限制；不会自动改用近似值。
- 负整数幂先求有界正幂，再执行一次最多 50 位、半值取偶的除法。因此 `2^-3=0.125`，但 `2^-200` 因中间正幂超过 50 位失败，`10^-1000` 因中间正幂上溢失败。
- 十进制除法舍入不触发 binary64；`(1/6)*6` 仍按精确乘法的 50 位限制报错。
- 科学函数的参数必须能转换为有限 binary64；非零参数不能下溢为零。因此 `ln(1e400)` 和 `sin(1e-400)` 分别报转换上溢和下溢。
- 近似计算不承诺 50 位精度或各平台末位完全一致；可判定的非零结果下溢为零时拒绝，例如 `exp(-1000)`。允许有限非零次正规结果。

这些规则通过内部接口回归验证，尚不是当前界面输入的验收预期。统一显示、复制／导出文本及历史／会话数据流仍待后续接入；本版不新增用户可选的备用计算模式或旧格式迁移。

## 安装与验证

退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 放入宿主 `plugin` 目录，重启后生效。

发布流程执行 Windows x64 Release 编译、计算引擎／Qt 页面／动态插件三组回归，校验 ZIP、源码提交、DLL 架构、导出及依赖。
实际测试计数与构建来源见 `BUILD-INFO.json`。界面继续按 `TESTING.md` 的现行浮点预期检查；真实 Windows 宿主的 DLL 加载、输入法、DPI 和关闭退出由用户手动确认。
