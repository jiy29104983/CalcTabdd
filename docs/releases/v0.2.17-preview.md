# CalcTabdd v0.2.17 测试版

本版相较 v0.2.16，将有界十进制与近似混算接入完整用户流程：普通计算、自定义公式、历史、ans、显示、复制、插入、导出和本地会话。
`0.1+0.2` 现在得到精确的 `0.3`，随后 `ans-0.3` 得到精确的 `0`。

## 相较 v0.2.16 的变化

- 数字字面量和自定义参数直接进入有界十进制，最多 50 位规范化有效数字、非零科学指数 -999 至 999。历史和 ans 保留数值类型及计算来源，失败不更新 ans。
- 十进制结果完整显示所有已保存数字；近似值按最近值／半值取偶生成最多 17 位可往返文本。显示、纯数值复制、插入和导出共用正文，例如 pi 为 `3.1415926535897931`。
- 科学指数 -6 ≤ E < 21 时使用普通小数，其余使用科学计数法；采用 ASCII 小数点、负号、小写 e 与有符号指数，不受地区小数逗号影响。
- 去掉结果中无意义的尾零，原公式和参数原文保留；负零在显示、复制、插入、导出和保存中统一为 `-0`。
- 结果下方另列“含除法舍入”“含近似计算”“含转换损失”，按此顺序组合。整数或零也保留上游来源；整条复制及 TXT／Markdown 包含同一来源说明。
- 长结果支持任意数字间软换行、完整选择和复制，保持公式在上、结果在下。视觉换行不会进入数字正文，窄窗口下保留记录操作入口。
- “插入历史结果”更名为“插入结果数值”，仍取该条当时的固定结果。普通模式负数和负零带括号，自定义参数使用有符号数字；撤销、输入法保护和显式提交规则保持。
- 本地会话改为 version 3，十进制保存规范正文，近似值保存原 binary64 位模式，完整保存类型、负零和来源。成功显示由保存值生成，恢复不重新计算历史。
- 会话读取严格校验类型、来源组合、规范文本、有限位模式和 ans 链；旧版本及未知版本拒绝且原文件不变。保留文件独占、原子写入、外部修改拒绝、16 MiB 和 10000 条记录限制。
- 更新运算帮助、安装说明和使用检查清单，增加独立 Decimal 格式化参考、类型化往返、长数字布局、近似来源和双窗口关闭恢复回归。

## 纯数值复用的边界

**复制纯数值、选中数字复制或插入结果数值后，再次提交时作为新十进制字面量，不继承原类型和来源。**
十进制文本可精确还原存储数值；近似文本转回 binary64 可恢复原位模式，但作为新输入时并不是原有的近似类型。
对有来源的结果，复制／插入后会显示非模态提示；剪贴板仍只含数字。

例如 `sin(0)` 后直接使用 `ans+0.1`，结果含近似计算及转换损失；复制数字 `0` 后计算 `0+0.1` 则为精确十进制 0.1、无原来源。
需要保留完整数值语义时使用 ans 或当前格式会话。整条复制和导出用于阅读，不是会话导入格式。

## 数值限制

- 加减乘逐节点精确计算，超出 50 位容量报错；除法每个节点最多 50 位，最近值／半值取偶。`1/3` 有舍入来源，`(1/6)*6` 因后续精确乘法超限失败。
- 十进制整数幂指数绝对值最多 10000；负整数幂先求有界正幂再取倒数，因此 `2^-200` 仍因中间正幂超限失败。`round(x)` 的半整数仍远离零。
- 科学函数、pi/e、非整数幂和非精确平方根使用 binary64；十进制转近似不能上溢或将非零参数变为零。`ln(1e400)`、`sin(1e-400)` 和 `exp(-1000)` 仍按相应范围限制报错。
- 显示 17 位不表示科学函数有 17 位准确度；不同平台重新计算可能末位不同，保存／恢复保留原值。来源标记不代表误差估计。
- 不增加任意精度、精确分数、精度设置或旧会话迁移。仅支持 version 3 会话，升级前可用旧版将需保留的历史导出为阅读文本。

## 安装与验证

退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 放入宿主 `plugin` 目录，重启后生效。目标为 Windows x64、Qt 5.15.2、MSVC v142；不要覆盖宿主 Qt DLL。

发布流程执行 Windows Release 编译、计算引擎／Qt 页面／动态插件三组回归，并校验 ZIP、源码提交、DLL 架构、导出和依赖。
实际测试计数与构建来源见 `BUILD-INFO.json`。真实 notepad-- 的加载、输入法、DPI、长数字选择和关闭退出须按 `TESTING.md` 单独确认，自动化不代表实机验收。
