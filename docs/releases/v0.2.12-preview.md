# CalcTabdd v0.2.12 测试版

本版相较 v0.2.11 简化自定义参数输入及会话读取。插件仍处于测试阶段。

## 相较 v0.2.11 的变化

- 自定义公式参数统一为每行一个，例如第一行 `x=1`、第二行 `y=2`。取消用空格或 Tab 在同行填写多个参数。
- 同行多参数会提示分行修正，不新增计算记录、不改变 ans；输入框保留原内容以便修改。
- 移除旧会话格式读取及字段迁移分支，只按当前完整结构保存和恢复两种模式的草稿、参数及历史。
- 清理帮助、安装说明和测试中的旧格式兼容、版本回退及同行输入支持要求。
- 继续保持显式计算：编辑参数时不计算或预览，Ctrl+Enter 或“计算”才追加代入式历史。

## 使用

底部“普通计算”菜单 → “定义／修改公式…” → 输入 `A=x+y` → “使用公式”。
在自动生成的参数行中填写：

```text
x=1
y=2
```

按 Ctrl+Enter 后，历史显示 `A=1+2`，下一行 `= 3`。Enter 换行，修改参数后再次确认即追加新记录。
成功后保留参数，两种模式分别保留草稿；默认不跨关闭保存，可通过“本地会话”主动开启保存。

## 安装与验证

退出所有 notepad-- 窗口，将 `plugin/calctabdd.dll` 放入宿主 `plugin` 目录，重启后生效。
会话只维护当前结构，不提供旧格式读取或迁移。文件损坏检查、独占锁和保存失败后的内存内容保留继续有效。

发布流程执行计算引擎、Qt 页面与动态插件三组测试，并验证 ZIP 校验和、提交、Windows x64 架构及插件导出。
实际结果见包内 `BUILD-INFO.json`；自动化结果不等于真实宿主的输入法、DPI 和完整关闭退出路径已验收。
