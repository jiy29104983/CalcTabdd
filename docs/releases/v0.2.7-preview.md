# CalcTabdd 0.2.7 测试版

在 0.2.6 基础上增加可选本地会话保存与恢复，保留计算结果、ans 与未提交草稿。

## 相比 0.2.6 的改进

- 新增“本地会话”菜单。默认关闭保存，选择新的 `.calctabdd` 文件并成功写入后开启自动保存。
  计算／清空立即保存，草稿和选区编辑短暂合并后保存；切换标签、关闭标签和窗口销毁时提交最后更改。
- 从空白计算器选择“恢复会话”，直接恢复公式、当时的数值及显示文本、错误范围、ans、草稿、选区和
  历史浏览中的临时编辑。旧公式不重新计算，下一次计算沿用保存的 ans 与记录编号。
- 文件按窗口独立管理，同一会话文件由一个窗口／进程独占；关闭后可在其他窗口恢复。
  新建／另存不覆盖已有文件，恢复不替换已有记录或草稿；未知格式版本、损坏文件安全拒绝。
- UTF-8 JSON v1 快照保存可往返数值与负零；完整写入后原子替换，禁止直接截断旧文件的回退。
  检测到外部文件修改时拒绝覆盖；保存失败持续提示，当前可见记录和草稿保留，可重试或另存到新文件。
- “停止保存”先提交最后更改再释放文件；文件保留，后续计算不再更新。清空会话也会更新已保存文件，
  确认框明确提醒，保持原草稿保护规则。
- 增加快照、版本／损坏校验、数值往返、写入失败、独立进程占用／异常退出、页面与动态插件的
  关闭恢复、多窗口隔离及明暗主题回归。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的 `plugin` 子目录，
重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
插件包不包含 Qt DLL，请勿覆盖宿主运行库。下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与模型、页面、动态 DLL 与 QScintilla 三组自动化测试及安装包
校验通过后发布。`BUILD-INFO.json` 记录提交、流水线和测试数量。真实宿主的文件位置选择、权限失败、
关闭退出、多窗口／多进程、输入法、主题和 DPI 请按 `TESTING.md` 复核，自动化不替代实机验收。

关闭／重启后默认打开空白计算器，需要用户显式选择文件恢复。输入法未上屏候选、撤销栈和滚动位置
不跨启动恢复。此版只支持格式 v1，单文件最多 16 MiB／10000 条记录，未知版本不作自动迁移。
TXT／Markdown 文件仍用于导出阅读，不能作为会话文件导入。

保存成功前不要关闭标签；持续写入失败或强制终止时，未成功写入的更改仍可能丢失。异常退出最多恢复
最后一次成功快照，不承诺断电耐久性。保存文件是用户所选位置中的可读文本，卸载 DLL 不会删除它。
