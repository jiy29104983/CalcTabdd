# CalcTabdd v1.0.6 测试版

本次增加程序员多进制复制、跨模式结果插入及混合记录导出。

## 本次变化

- 程序员记录的“记录操作”支持复制 DEC 纯数值及 HEX／BIN／OCT。
  位模式带进制前缀、保留完整位宽，复制时去掉分组与视觉换行。
- “插入结果数值”固定插入十进制。普通／程序员表达式的负数带括号，
  自定义参数保留符号；替换选区或插到光标处，支持撤销／重做。
- 向程序员插入结果时，检查保存值本身为当前范围内的整数。
  小数、负数转无符号和越界值拒绝，保留原输入与选区，不截断或回绕。
- 数学结果即使有舍入、近似或转换损失，实际保存值为范围内整数也可插入，
  并按新整数文本处理。长近似整数从保存值生成完整正文，避免显示舍入改变数值。
- 整条复制和 TXT／Markdown 导出包含原模式、位宽、符号、公式、
  DEC／HEX／BIN／OCT 四种结果及非空回绕来源；失败记录包含配置和错误。
- 支持普通、自定义和程序员混合历史，逐条保留原配置；详情折叠或当前设置改变
  不影响文本，不重新计算历史，不导出未提交草稿或临时编辑。
- 同步帮助、安装说明和使用检查清单。

## 当前使用范围

纯数值文本不携带原类型、位宽、符号或计算来源，粘贴后按目标模式解释。
TXT／Markdown 供阅读和留存，不能用于恢复会话。

程序员会话保存与恢复尚未开放，关闭标签后不保留，可先导出记录留存过程。
已开启数学会话保存时，须先停止保存再进入程序员；使用程序员后，
请在新空白计算器中保存或恢复数学会话。数学会话继续使用 version 3。

## 安装与验证

下载对应 Windows x64 ZIP 和 `.sha256` 文件，退出 notepad-- 后替换
`plugin/calctabdd.dll`，重启后在“关于 CalcTabdd”确认版本 **1.0.6**。
目标工具链为 Qt 5.15.2 / MSVC v142。

测试包在 Windows Release 引擎、页面、动态插件回归、Debug 页面回归及包校验
通过后生成。提交和测试结果见 `BUILD-INFO.json`。真实 Windows 宿主的加载、
输入法、DPI 和关闭退出仍需按包内 `TESTING.md` 检查。
