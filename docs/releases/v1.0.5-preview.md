# CalcTabdd v1.0.5 测试版

本次完善程序员模式的连续计算、三模式草稿与历史回填，修正历史浏览中的状态切换问题。

## 本次变化

- 普通／自定义共享数学 ans，程序员独立使用整数 ans；失败保留原值和来源。修改位宽或符号后，
  实际引用整数 ans 时才检查能否保持原数值，不截断、不重新解释位模式。
- 三种模式分别保留草稿、光标与选区，程序员草稿还保留位宽和符号；历史中的临时编辑不会改写原记录。
- 历史回填恢复原模式和配置，重新提交使用当前对应 ans。成功后返回原草稿，失败保留待修正，
  浏览计数随新增错误记录及时更新。
- 修正历史浏览中首次进入自定义定义栏未结束浏览的问题；应用或取消定义后原草稿仍可恢复。
- 修正程序员历史公式修改位宽或符号后，来回浏览仍显示旧配置错误标记的问题。
- 清空提示明确同时重置数学与整数 ans，保留三份原草稿及程序员设置；其他窗口继续独立计算。
- 同步帮助和使用清单，补充跨设置 ans、历史失败保护、草稿恢复和两窗口检查步骤。

## 当前使用范围

程序员内容仅在当前窗口保留，关闭标签后不保留。可以选中显示文字复制；
各进制专用复制菜单、结果插入、含程序员记录的导出及程序员会话保存尚未开放。
已开启数学会话保存时，须先停止保存再进入程序员；使用程序员后请在新空白计算器中保存或恢复数学会话。
数学会话继续使用 version 3，原文件不会升级。

## 安装与验证

下载对应 Windows x64 ZIP 和 `.sha256` 文件，退出 notepad-- 后替换 `plugin/calctabdd.dll`，
重启后在“关于 CalcTabdd”确认版本 **1.0.5**。目标工具链为 Qt 5.15.2 / MSVC v142。

测试包在 Windows Release 引擎、页面、动态插件回归、Debug 页面回归与包校验通过后生成。
提交和测试结果见 `BUILD-INFO.json`。真实 Windows 宿主的加载、输入法、DPI 和关闭退出
仍需按包内 `TESTING.md` 检查。
