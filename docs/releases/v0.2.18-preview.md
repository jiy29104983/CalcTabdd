# CalcTabdd v0.2.18 测试版

本版相较 v0.2.17，精简“关于”与帮助说明，并修复计算器背景透出宿主行号栏和当前行高亮的问题。
继续采用公式在上、结果在下的布局，保留现有计算、历史、复制、导出和本地会话行为。

## 相较 v0.2.17 的变化

- “关于 CalcTabdd”改为紧凑布局，仅显示产品名称、用途、版本和开源许可，去除构建环境、源码提交及调试验收说明。
- 按当前数值规则修订运算与精度帮助，用操作和例子说明十进制、近似计算、舍入与复用边界。
  除法结果最多保留 50 位有效数字；有限小数超过容量时同样会舍入，例如 `1/(2^100)`。
- 明确自定义公式可按 Ctrl+Enter 或点击“计算”提交；普通模式标出公式错误位置，自定义模式在状态区提示错误。
- 将历史召回、复制与会话说明中的开发术语改为使用说明，保留函数名称、搜索关键词和 @ 补全模板。
- 修复页面背景绘制：标题、会话提示及底部输入区完整覆盖宿主编辑器，不再露出灰色行号栏、行号“1”或当前行高亮。
  增加明暗主题、宽窄窗口和标签切换后的背景覆盖回归。
- 同步中文安装说明与使用检查清单。计算规则与会话格式保持 v0.2.17 的行为。

## 安装与验证

退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 放入宿主 `plugin` 目录，重启后在“关于 CalcTabdd”确认版本为 **0.2.18**。
当前插件菜单提供“打开计算器”“运算与精度帮助”“关于 CalcTabdd”；已取消的“查看文档选区”不再提供。
目标为 Windows x64、Qt 5.15.2、MSVC v142，不要覆盖宿主 Qt DLL。

发布流程执行 Windows Release 编译、计算引擎／Qt 页面／动态插件三组回归，并校验安装包。
实际测试计数与构建来源见 `BUILD-INFO.json`。真实 notepad-- 的加载、输入法、DPI、主题切换及关闭退出仍须按 `TESTING.md` 单独确认。
