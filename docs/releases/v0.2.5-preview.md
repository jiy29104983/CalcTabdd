# CalcTabdd 0.2.5 测试版

在 0.2.4 基础上改进错误定位与数学定义域提示，并补齐双精度数值边界回归。

## 相比 0.2.4 的改进

- 计算失败时用底色和波浪线标记问题字符、参数或运算符，光标移到问题处，状态栏显示行列。
  修正前导空白导致的定位偏移，支持多行、Unicode 运算符和完整 emoji 字符范围。
  末尾缺少括号／操作数时突出所在行并定位插入点；标记不会成为输入替换选区。
- 除零定位到除数，未知函数／常量定位到名称，函数参数不足或过多给出明确提示。
  `ln(0)` 和 `log(0)` 现在说明“参数必须大于 0”，修正此前误报溢出的情况；
  `sqrt(-1)`、负底数的非整数次幂、0 的负数次幂分别解释其定义域限制。
- 编辑、开始输入法组词或清空会话后移除旧标记；回填未修改的错误公式可查看其历史诊断。
  失败继续保留公式与上次成功的 `ans`，修正后追加记录，已有历史结果不变。
- 数值字面量过大／下溢现在有独立提示。沿用既有规则：`1e-400` 转换下溢时拒绝输入，
  `1e-200*1e-200` 等运算下溢可以得到有符号零；`0^0` 仍为 1。
- 增加精确错误范围、失败保护 ans、大整数边界、浮点取余、消去、下溢、负零和结果逐位往返回归。
  覆盖错误修正、历史召回、输入法事件、撤销、主题切换、多窗口及原生编辑器缓冲区隔离。
  修正运行中切换深色调色板后输入文字和状态文字颜色未更新的问题。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的
`plugin` 子目录，重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
插件包不包含 Qt DLL，请勿覆盖宿主运行库。下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与模型、页面、动态 DLL 与 QScintilla 三组自动化测试
及安装包校验通过后发布。包内 `BUILD-INFO.json` 记录提交、流水线和测试数量。
实际宿主中的错误定位、中文输入法、主题、DPI、窗口切换和关闭退出请按 `TESTING.md` 复核，
自动化不替代实机验收。

内部仍为 double，最多显示 15 位有效数字，数值复制／插入仍采用可往返格式。
大整数、消去误差及奇点附近的有限结果不自动修正，不承诺任意精度或统一误差上限。
本版不增加跨启动历史保存、批量计算或新函数。
