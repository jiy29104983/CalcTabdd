# CalcTabdd 0.2.1 测试版

在 0.2.0 基础上整理计算记录的内部管理，保持上下分行界面和现有操作方式。

## 相比 0.2.0 的改进

- 计算记录由独立会话模型管理，统一保留编号、公式、成功或失败结果、内部数值、
  显示文本、错误位置和计算前的 `ans`。历史回填按记录编号读取原公式。
- 内部数值与显示文本分开保存，连续计算继续使用未舍入的 `double` 值。
  失败记录保留原错误，不改变上一条成功结果。
- 回填旧公式后追加新计算，含 `ans` 的公式仍使用当前会话状态；原记录保持不变。
  每个窗口独立持有会话，关闭标签或退出后清空。
- 增加记录顺序、稳定编号、错误保留、显示精度与内部数值区别、追加后的旧公式回填、
  输入拦截，以及多窗口切换、关闭重开回归。安装包检查清单增加对应操作示例。

## 安装与兼容性

退出所有 notepad-- 窗口，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的
`plugin` 子目录，重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。升级前可备份原 DLL。

目标环境保持 Windows x64、Qt 5.15.2、MSVC v142。宿主源码接口参考提交为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）；
源码参考不等于所有发布二进制都经过实机验证。插件包不包含 Qt DLL，请勿覆盖宿主运行库。
下载后使用 `Get-FileHash <ZIP路径> -Algorithm SHA256` 与同名 `.sha256` 文件核对。

## 验证与当前边界

测试包在 Windows Release 编译、引擎与记录模型、页面、动态 DLL 与 QScintilla
三组自动化测试以及包校验通过后发布。包内 `BUILD-INFO.json` 记录源码提交、流水线和测试数量。
完整 Windows 宿主中的加载、关闭退出、输入法及 DPI 仍请按包内 `TESTING.md` 复核。

本版为预发布测试版。计算算法、15 位有效数字显示、Ctrl+Enter 提交及 `@` 补全规则保持不变；
没有新增数值复制／插入、会话清空按钮、导出或跨启动保存功能。
