# CalcTabdd v1.0.11

本版本扩展普通／自定义公式的数学函数，改善大量历史记录的显示与自动保存性能，并修复首次定义自定义公式时的草稿保护问题。

## 数学函数

- 内置函数由 14 个增加至 26 个，新增 `cbrt`、`hypot`、`asin`、`acos`、`atan`、`atan2`、`rad`、`deg`、`log2`、`trunc`、`sum` 和 `avg`。
- `round(x,n)` 支持指定小数位舍入，`log(x,base)` 支持指定底数；原有单参数用法继续可用。
- `min`、`max` 支持多个参数，`sum` 和 `avg` 支持求和与平均值。
- 帮助、`@` 补全和使用说明同步提供新函数。为兼容已有自定义公式，新增函数名未跟括号时仍可作为公式名或参数名。

## 历史记录与自动保存

- 历史记录按每页最多 100 条显示，默认显示最近一页，使用“较早记录／较新记录”翻页。
  分页不裁剪历史；保存、TXT／Markdown 导出和 `Alt+↑ / Alt+↓` 召回仍包含全部记录。
- 自动保存复用未变化的历史快照与序列化记录，减少仅修改草稿或光标时的重复处理。
  保存仍写入完整会话文件，并保留输入校验、外部文件改动检测和保存失败后的重试保护。
- 首次定义自定义公式期间暂时禁用“插入结果数值”，避免修改隐藏的普通／程序员草稿；应用或取消定义后恢复。

## 构建

- 修复重复配置时生成的宿主测试头文件时间戳变化造成的无效重编译。
- Windows Release 和 Debug 编译采用单任务及较低进程优先级。

## 会话与安装

继续使用 **version 4** 会话；version 3 及更早文件不能直接恢复，不提供迁移。
保存默认关闭；需要关闭后继续计算时，请先开启保存，之后从新的空白计算器手动恢复。

1. 下载 Windows x64 ZIP 和同名 `.sha256` 校验文件。
2. 退出所有 notepad-- 窗口，将 `plugin/calctabdd.dll` 放入宿主的 `plugin` 目录并替换旧 DLL。
3. 重启，在“关于 CalcTabdd”确认版本 **1.0.11**。

目标运行库为 **Qt 5.15.2 / MSVC v142**，无需覆盖宿主的 Qt DLL。
可用 PowerShell 的 `Get-FileHash <ZIP路径> -Algorithm SHA256` 核对校验值。
