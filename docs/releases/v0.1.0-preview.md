# CalcTabdd 0.1.0 测试版

首个可安装的 Windows x64 测试版本，采用“公式在上、结果在下”的计算记录界面。

## 主要功能

- 新增正式插件入口，从插件菜单打开独立计算器标签；每个窗口独立管理记录。
- 新增四则运算、括号、小数、科学计数法、乘方、取余、常量、ans 和常用数学函数。
- 底部输入支持 Ctrl+Enter 和计算按钮；计算错误直接显示在对应记录内，保留公式便于修改。
- 支持公式复用、结果选中复制、历史滚动、原生标签焦点接入和菜单命令隔离。
- 建立本地与 Windows 自动化测试、实际 DLL 加载检查及带校验和的安装包。

## 安装与兼容性

退出 notepad--，将 ZIP 中 `plugin/calctabdd.dll` 复制到安装目录的 `plugin` 子目录，
重启后选择“插件 → CalcTabdd 计算器 → 打开计算器”。包中含中文安装说明与手测清单。

编译目标：Windows x64、Qt 5.15.2、MSVC v142。宿主公开源码基线为
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
请勿使用 32 位宿主或覆盖宿主 Qt DLL。下载后可用 `Get-FileHash <ZIP路径> -Algorithm SHA256`
与同名 `.sha256` 文件核对。

## 验证与当前边界

此测试包只在 Windows Release 编译、三组自动化测试及包校验全部通过后发布。
包内 `BUILD-INFO.json` 记录测试组、通过数量、源码提交和流水线编号。

请按包内 `TESTING.md` 确认加载、菜单、关闭退出、输入法与 DPI 在当前宿主中的表现。

计算使用双精度浮点，最多显示 15 位有效数字；`%` 是取余，三角函数使用弧度。
计算记录仅保留在当前标签，关闭或退出后清空。本版为预发布，等待手动测试反馈。
