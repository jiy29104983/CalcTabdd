# CalcTabdd v1.0.10

本版本精简三个模式的输入区，让公式、参数与计算按钮更容易找到，并更新使用说明和界面截图。

## 输入区更简洁

- 保留普通计算模式、自定义公式模式和程序员模式的现有名称及切换方式。
  移除重复的输入标题和常驻教学文字，输入框外集中显示当前计算需要的控件。
- 普通／程序员输入框为空时，在框内显示公式示例、`@ 补全` 和 `Alt+↑↓ 召回历史`；
  输入内容后自动隐藏，清空后重新出现。计算快捷键仍为 Ctrl+Enter，也可在“计算”按钮的悬停提示中查看。
- 自定义公式保留“公式定义”和“填写参数”两个分区，去掉重复的参数摘要及常驻“已应用”标签。
  定义修改后显示“未应用”，应用或还原后隐藏；空白定义栏提示 @ 补全，参数框只提示逐行填写与历史召回。
- 程序员位宽、类型和简短的“^ 异或”提醒集中显示；会话保存说明放在顶部“本地会话”入口和帮助中。
- 计算成功、设置更新等普通反馈约 4 秒后清除。错误、缺少参数、未应用公式和历史浏览状态按需保留，
  保存失败仍使用独立的会话提示区。

## 使用说明与截图

- README 更新三个模式的使用方式和本版实际 Qt 页面截图，并注明截图环境。
- 修正 README 中遗留的程序员会话限制说明。三个模式均支持记录复用、混合 TXT／Markdown 导出和本地会话保存恢复。
- 同步插件帮助、安装说明与使用检查清单，区分公式定义栏和参数输入框可使用的快捷键。

## 计算与会话

本版保持现有计算规则、输入快捷键、历史与草稿行为。普通／自定义共享数学 `ans`，程序员使用独立整数 `ans`。
程序员 `^` 仍为异或，普通／自定义的 `^` 仍为乘方。

继续只读写 **version 4** 会话，**version 3 及更早文件不能直接恢复，不提供迁移**。
保存默认关闭；需要关闭后继续计算时，请先开启保存，之后从新的空白计算器手动恢复。

## 安装

1. 下载 Windows x64 ZIP 和同名 `.sha256` 校验文件。
2. 退出所有 notepad-- 窗口，将 `plugin/calctabdd.dll` 放入宿主的 `plugin` 目录并替换旧 DLL。
3. 重启，在“关于 CalcTabdd”确认版本 **1.0.10**。

目标运行库为 **Qt 5.15.2 / MSVC v142**，无需覆盖宿主的 Qt DLL。
可用 PowerShell 的 `Get-FileHash <ZIP路径> -Algorithm SHA256` 核对校验值。
