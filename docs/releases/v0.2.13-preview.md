# CalcTabdd v0.2.13 测试版

本版相较 v0.2.12 优化整个计算器界面的布局、明暗配色和按钮操作一致性。

## 相较 v0.2.12 的变化

- 标题、记录数与顶部操作栏分层显示。导出、本地会话、清空、帮助按钮按字体统一高度，窄窗口中自动换行。
- 计算记录使用更清楚的边界和留白，回填按钮与操作菜单对齐；继续保持公式在上、结果在下。
- 底部输入框占满可用宽度，参数定义单独展示；右下角“计算”为主按钮，减少重复提示。
- 主界面、菜单、公式定义、文件选择、确认窗口、帮助与补全共用配色，补齐悬停、按下、禁用、焦点及深色滚动条样式。
- 中文输入法组词时，“计算”和回填按钮同步禁用；结束组词后恢复。
- 清空及覆盖按钮标明破坏性操作，确认窗口继续默认取消；帮助内容增加阅读留白。
- 增加窄窗口、大字体、实际按钮点击、键盘提交和打开窗口后的主题切换回归。

## 操作规则

计算仍由 Ctrl+Enter 或“计算”确认。自定义公式每行一个参数，编辑时不实时计算；普通草稿与自定义参数分别保留。
关闭后的保留规则统一由“本地会话”控制，默认不保存。只维护当前会话结构，不提供旧格式读取或迁移。

## 安装与验证

退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 放入宿主 `plugin` 目录，重启后生效。

发布流程执行 Release 构建及计算引擎、Qt 页面、动态插件三组测试，并验证安装包校验和、提交、Windows x64 架构与插件导出。
实际结果见 `BUILD-INFO.json`。真实宿主的主题、100%／150%／200% DPI、中文输入法、关闭退出仍需按包内检查清单手动确认。
