# CalcTabdd v0.2.20 测试版

本版相较 v0.2.19，精简底部计算模式菜单，移除重复的公式编辑入口。

## 相较 v0.2.19 的变化

- 删除“定义／修改公式…”菜单项及其分隔线，模式菜单仅保留“普通计算模式”和“自定义公式模式”。
- 公式定义和后续修改继续在页面内的定义栏完成：直接点击编辑，Enter 应用，@ 补全函数，Esc 还原。
- 同步模式按钮提示与使用检查清单，验证切换模式、直接编辑、输入法保护和宿主编辑菜单的行为。

## 安装与验证

退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 替换到宿主 `plugin` 目录，重启后在“关于 CalcTabdd”确认 **0.2.20**。
目标为 Windows x64、Qt 5.15.2、MSVC v142；不要覆盖宿主 Qt DLL。

发布流程执行计算引擎、Qt 页面与动态插件三组 Windows Release 回归，并校验安装包；计数见 `BUILD-INFO.json`。
真实 notepad-- 的菜单、输入法、主题、DPI 与关闭退出仍须按 `TESTING.md` 单独确认。
