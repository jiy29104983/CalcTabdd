# CalcTabdd 0.2.9 测试版

相对 0.2.8，本版新增普通文档的只读选区查看。

## 新增功能

- 插件菜单新增“查看文档选区（只读）”，显示来源标签、打开时的选区文本与换行统计。
- 支持单个连续选区的中文、emoji、跨行、正向／反向选择和只读文档；读取保留原文、选区、撤销和剪贴板。
- 无选区会提示；列选区、多选区、虚拟空格以及二进制、分页大文件、计算器标签会明确拒绝。
- 切换标签或关闭源标签会关闭预览；不同宿主窗口分别读取各自的当前文档。
- 本版仅查看，不自动计算、复制或写回源文档。既有计算与会话保存功能保持可用。

## 兼容与验证

- 使用宿主实际加载的编辑库公开入口，核对对象与模块归属，再通过 Scintilla 的指针宽度接口只读查询。
  不使用 0.2.8 探针确认有问题的输入法查询，也不依赖无障碍选区缓存。
- 不随包携带或替换 QScintilla／Qt DLL；接口缺失或不匹配时提示不可用。
- 增加字符、换行、NUL、只读、选区模式、不变性、菜单和生命周期回归。
- Windows 流水线同时在校验过 SHA256 的官方 v3.8.3／v3.9.0 发行包中执行自动化选区与插件预览检查。
  结果摘要写入安装包 BUILD-INFO.json。该自动化验证与用户对完整交互、输入法、DPI 和退出流程的手动验收分开记录。

## 安装

退出所有 notepad-- 窗口，备份原插件后，将包内 `plugin/calctabdd.dll` 放入宿主的 `plugin` 目录。
不覆盖宿主运行库。重新启动后，在普通文档选中文字并使用新增菜单；具体检查见包内 `TESTING.md`。
