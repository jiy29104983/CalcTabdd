# 项目任务执行工作流

本项目技能为 `calctabdd-task`，入口在
[.agents/skills/calctabdd-task/SKILL.md](../.agents/skills/calctabdd-task/SKILL.md)。
它用于开发和交付 CalcTabdd 需求，技能和交接随仓库维护。

## 触发方式

| 输入 | 行为 |
| --- | --- |
| `执行 EVO-002 任务` | 定位该需求，查询交接与当前代码，完成实现和交付 |
| `执行 独立计算记录模型 任务` | 按唯一需求名称匹配；不唯一时澄清 |
| `继续 EVO-002 任务` | 从现有交接与实际进展继续 |
| `执行下一个任务` | 先恢复未完成工作，否则根据路线图优先级和依赖选择一项 |
| `下一个任务是什么？` | 只读查询和推荐，不启动实现或推送 |
| `$calctabdd-task 执行 EVO-002 任务` | 显式指定该技能 |

自然语言触发通过技能描述匹配；若当前会话未显示新技能，可重启会话后使用显式调用。
用户更具体的限制（例如“只调研”“不推送”）优先；技能不绕过环境权限或 GitHub 审批。

## 每个任务的交付过程

1. 阅读[路线图](roadmap.md)、[交接索引](handoffs/README.md)、当前任务详情和实际代码，确认进展及下一动作。
2. 说明目标、范围和验证安排后实现；已有执行授权不重复确认，只有不能推断的关键产品选择才澄清。
3. 本地 Release 构建和三组测试通过，并完成新增/修改文档检查。
4. 提交、推送，核对远端 SHA；监控该 SHA 的工作流，失败时读日志、修复、复测并再次推送，直到必要作业通过。
5. 有发布包时下载并独立校验，分开报告自动化和实机状态。
6. 更新任务状态，按模板写交接和下一任务；推送文档收尾提交并核对其 CI，在最终回复报告结果。

交接记录功能提交的验证事实，最终回复报告收尾提交的结果；不为把文档自身提交号写回而无限追加提交。
外部权限或环境阻塞无法解除时，记录 `blocked` 与恢复步骤，不能把等待或失败说成完成。

## 只读查询与技能验证

```bash
python3 .agents/skills/calctabdd-task/scripts/task_context.py --next
python3 .agents/skills/calctabdd-task/scripts/task_context.py --task EVO-002
python3 -B .agents/skills/calctabdd-task/scripts/test_task_context.py -v
```

查询脚本列出任务范围、状态、依赖提示、相关产品决定和应读交接文件；它不执行任务、不联网、不改状态。
脚本的候选排序是辅助提示，条件依赖和交接冲突仍由执行者核对。
模板和具体交付命令位于技能包中，避免在本页维护另一套流程。
