# CalcTabdd

notepad-- 的标签页计算器插件，使用 C++14 / Qt 5.15。名称中的 `dd` 表示 `--`。
当前版本 **0.2.8 测试版**，采用“公式在上、结果在下”的连续计算记录布局。

## 安装与使用

1. 下载 Windows x64 测试包，退出所有 notepad-- 窗口。
2. 将包中的 `plugin/calctabdd.dll` 放入 notepad-- 安装目录的 `plugin` 文件夹。
3. 重启 notepad--，选择 **插件 → CalcTabdd 计算器 → 打开计算器**。
4. 在底部输入公式，点击“计算”或按 **Ctrl+Enter**；普通 Enter 不提交。
5. 上方按顺序显示公式和结果。“再次使用 / 修改公式”可将原公式放回输入区；结果可选中复制。
   回填后提交会追加一条新记录；含 `ans` 的旧公式使用当前会话的上次成功结果，原记录保持不变。

每条记录右侧的 **记录操作** 菜单提供：

- **复制纯数值**：不带 `=`，使用内部数值的可往返格式。例如 `0.1+0.2` 显示 `0.3`，
  复制得到 `0.30000000000000004`，重新输入可恢复相同内部值。
- **复制整条计算**：复制原公式和下一行的 `= 数值`；失败记录复制原公式和错误说明。
- **插入历史结果**：将当时的固定数值插入底部输入框的光标位置，替换选中文字；负数带括号，
  如 `(-2)^2` 得到 `4`。保留前后内容，支持撤销／重做，编辑完成后再提交计算。

失败记录不提供“复制纯数值”和“插入历史结果”。复制／插入不更新 `ans`、不新增记录，
也不恢复旧公式的计算上下文。需要乘法时仍须输入 `*`，插入不会自动补运算符。

每个宿主窗口拥有独立计算器。重复打开会回到已有标签；重开默认为新的计算会话。
本地保存默认关闭，可主动开启并在关闭／重启后从文件恢复。卸载时退出宿主并删除 `plugin/calctabdd.dll`。

计算器激活时，宿主菜单中的复制、粘贴、剪切、全选、撤销、重做作用于计算器；保存、另存为、
查找替换等文本文件命令临时不可用。切回普通文档后恢复原操作。

## 查看文档选区

在普通文本文档中选中文字，选择 **插件 → CalcTabdd 计算器 → 查看文档选区（只读）**。
窗口显示来源标签、选区文本快照、UTF-16 长度与 CRLF／LF／CR 换行数量，便于核对中文前缀、
emoji 和跨行选区。普通只读文档同样可用，无选区时给出提示。

- 查看操作保持源文档、选择范围、修改标记、撤销记录和剪贴板不变，也不会创建计算器或追加计算记录。
- 每次从命令所属窗口的当前标签读取；两个窗口独立。切换标签、关闭源标签或关闭窗口时，查看窗口关闭。
  快照不会自动刷新；重新打开会读取新的选区。预览中的换行统一显示为分行，原换行类型以计数为准。
- 本入口用于查看和核对，尚不提供“计算所选公式”、源位置跳转或结果写回。
  计算器、二进制及分页大文件标签不支持此入口。
- 显示内容遵循宿主的文本选区规则：NUL 字符会变为空格；列选区按行合并，多选区可能直接拼接。
  不提供原始字节、各子选区范围或可用于写回的坐标，不能将其当作二进制内容提取工具。

## 本地会话保存与恢复

- 默认不保存。点击右上角 **本地会话 → 开启保存／另存新文件…**，选择本地目录和新文件名，
  首次默认打开“文档”目录，自动补 `.calctabdd` 后缀。首次保存成功后，当前标签才开启自动保存。
  已有文件不覆盖；要继续已有会话，请使用“恢复会话”。
- 开启后，提交计算和确认清空会话会立即保存，已上屏草稿、光标、选区和历史浏览状态在停止编辑
  约 200 毫秒后保存；切换标签、关闭标签或窗口销毁时也尝试保存最后更改。
  输入法尚未上屏的候选、文字撤销栈、滚动位置和帮助窗口不保存。
- 文件保留原公式、当时结果与显示文字、错误分类和范围、计算前的 `ans`、当前 `ans`、草稿及
  历史召回中的临时编辑。数值采用可往返格式，保留负零；恢复直接读取这些快照，**不会重新计算旧公式**。
- 关闭标签或退出后，已保存文件仍保留。重开计算器默认是空白页，通过 **本地会话 → 恢复会话…**
  选择该文件；恢复成功即继续自动保存到该文件。恢复要求当前页没有记录、没有草稿且未开启保存，
  不会替换正在使用的会话。恢复后提交新公式继续使用已保存的 `ans` 和下一编号。
- 每个窗口独立选择文件。同一个文件同时只允许一个 CalcTabdd 窗口／进程打开，其他窗口会提示占用。
  关闭持有会话的标签后可在另一窗口恢复；只切换到普通文档仍保留文件占用。
  文件以可读的 UTF-8 JSON 保存；保存目录中的 `.lock` 文件用于占用保护，正在使用时不要删除它。
- **立即保存／重试** 可主动保存。写入失败会持续显示原因，当前记录和草稿仍在；可以重试，或另存到
  新文件。文件被外部修改、损坏或格式版本不受支持时，不覆盖原文件、不作部分恢复。
  新建／另存失败会保留原保存状态和当前内容。文件完整写入后才替换目标，不回退到直接截断旧文件。
- **停止保存（保留文件）** 会先保存最后更改，再释放文件；失败时继续保留当前保存状态。
  后续计算只在标签中保留，原文件不删除。开启保存时，**清空会话也会更新保存文件**，确认框会提示，
  不提供历史文件回收站或清空撤销。
- 此版只支持会话格式 v1，未知版本安全拒绝，需使用匹配的插件版本读取；不会静默降级重写。
  单个保存文件最多 16 MiB、10000 条记录，超限时保留当前可见内容并提示，可先导出记录。
  TXT／Markdown 导出仍用于阅读，不能作为会话文件恢复。
- 保存成功前不要关闭标签；若磁盘、权限等问题持续存在，强制关闭仍会丢失未成功写入的更改。
  异常终止最多恢复最后成功保存的快照，不承诺尚未保存的输入、断电或所有文件系统上的持久性。
  文件位于用户选择的位置，卸载 DLL 不会删除这些文件。

## 导出计算记录

- 点击右上角 **导出记录**，选择 **导出为 TXT…** 或 **导出为 Markdown…**，再选择文件位置。
  没有填写扩展名时自动补 `.txt` 或 `.md`；已有文件需要再次确认覆盖，默认取消。
- 导出当前窗口的全部已提交记录，按编号顺序保留原公式、当时的成功结果和失败时的错误说明。
  不重新计算含 `ans` 的旧公式，不导出尚未提交的草稿或历史公式的临时编辑。
- 成功结果沿用“复制整条计算”的可往返格式，最多 17 位有效数字并保留负零。
  例如 `0.1+0.2` 导出为 `0.30000000000000004`；这不会提高原计算精度。
- 两种格式均为 **UTF-8（无 BOM）**、LF 换行。TXT 使用编号和分行文本；Markdown 使用分节与
  代码块，中文、换行、反引号、HTML 和其他特殊字符按原文保留。
- 成功、取消或失败均不改变记录、`ans`、草稿、选区、撤销记录及历史浏览状态。
  写入失败时状态栏显示原因，记录仍保留；可再次点击同一导出入口重试或另选位置。
  文件完整写入后才替换目标，无法完成保存时不以直接截断方式覆盖旧文件。
- 空会话或中文输入法组词期间导出按钮不可用。导出窗口仅限制所属宿主窗口，其他窗口仍可计算；
  切换到普通文档、关闭计算器标签或关闭所属窗口会取消未完成的导出。
  导出文件供阅读和留存，当前没有从 TXT／Markdown 恢复计算会话的功能。

## 错误定位与修正

- 计算失败时，输入框用底色和波浪线标记问题字符、参数或运算符，光标移到问题处，
  状态栏显示行号和列号。前导空白、多行与 Unicode 运算符均计入定位；输入全文保留。
- 末尾缺少右括号或操作数时，光标停在应补充内容的位置，并突出所在行。
  标记只用于提示，不会自动选中文字；继续输入不会替换整段错误参数。
- `ln(0)`、`log(-1)` 提示参数必须大于 0，`sqrt(-1)` 提示参数必须大于或等于 0。
  负底数的非整数次幂、0 的负数次幂会解释实数定义域限制；`0^0` 沿用结果 `1`。
  函数参数不足／过多、未知名称、除零与溢出各有对应提示。
- 编辑、开始输入法组词或确认清空会话后，旧标记消失；重新提交时重新定位。
  通过“修改公式”或 Alt+↑↓ 回填未修改的错误公式时显示该条的历史诊断，临时编辑后须重新计算。
- 失败会保留上次成功结果 `ans`，修正后提交追加新记录。原错误记录继续保留。

## 历史召回与草稿

- 在底部输入框按 **Alt+↑** 从最新一条向前召回，按 **Alt+↓** 向后浏览；
  向后越过最新一条会返回召回前的草稿。最旧处不循环，无历史时不改变输入。
- 首次召回保存草稿全文、光标和选区，包含空白及粘贴的多行内容。
  浏览期间各条公式的临时编辑会保留，返回草稿或成功提交后结束本轮浏览；原历史记录始终不变。
- 召回后可修改，按 **Ctrl+Enter** 或点击“计算”才追加计算，使用当前 `ans`。
  成功后返回原草稿；失败保留公式和错误位置，可修正后重试。“再次使用 / 修改公式”也采用此规则。
- 普通 ↑↓ 继续移动光标，Shift+方向键继续选择文字。输入法组词或 `@` 候选打开时，
  Alt+↑↓ 不召回历史；可先完成组词或按 Esc 关闭补全，再召回。
- 切换浏览项会重置输入框撤销栈；当前项的文字编辑和结果插入仍可撤销／重做。
  未开启本地保存时，草稿和临时编辑在关闭标签或退出后清空；开启后可从会话文件恢复。

## 清空会话

- 点击右上角 **清空会话**，确认后删除当前窗口的全部成功和失败记录，`ans` 重置为 `0`，
  下一条记录从 `01` 开始。清空后可以继续计算；其他窗口的记录、结果和草稿不受影响。
- 普通输入中的草稿、光标、选区和文字撤销记录保留。若正在浏览历史公式，则返回召回前的
  原始草稿及选区，并丢弃本轮历史公式的临时编辑；确认框会明确提示这一点。
- 确认框默认选择“取消”，按 Esc 或关闭确认框也会取消，原会话保持不变。
  **清空记录不可撤销**，没有单条删除功能；输入框的文字撤销不会恢复计算历史。
- 没有记录或输入法正在组词时，“清空会话”不可用；完成组词后可以操作。
  草稿中的 `ans` 在清空后会引用 `0`，例如保留 `ans+1` 再计算会得到 `1`。

## 帮助与快捷补全

- 点击右上角的 **帮助**，或选择 **插件 → CalcTabdd 计算器 → 运算与精度帮助**。
  帮助窗口可保持打开，支持英文名称与中文关键词搜索，包含运算示例、语法和精度限制。
- 在公式需要函数或常量的位置输入 `@`，列出 14 个函数与 `pi`、`e`、`ans`。
  例如 `@sq`／`@平方根` 查找 `sqrt`，`@对数` 查找 `ln`／`log`，`@上次` 查找 `ans`。
  使用 ↑↓ 选择、Enter 或 Tab 插入、Esc 关闭，也可点击候选。`/` 继续作为除号。
- 选择后仅替换当前 `@关键词`，保留公式前后内容。`2+@sq` 会变成 `2+sqrt()`，光标进入括号；
  `@pow` 插入 `pow(, )`，光标位于第一个参数处。已有括号和参数不重复插入，支持撤销／重做。
- 未完成的 `@` 查询会阻止提交。输入法组词期间由输入法处理候选，文字上屏后再匹配。
- **插件 → CalcTabdd 计算器 → 关于 CalcTabdd** 显示插件版本、目标运行库和宿主兼容参考。

## 运算与语法

| 类别 | 写法与规则 | 示例 |
| --- | --- | --- |
| 四则运算 | `+ - * /`，乘除优先于加减，同级从左到右 | `1+2*3 = 7` |
| 取余 | `%` 是浮点取余，非零余数与被除数同号，不是百分比 | `5.5%2 = 1.5` |
| 乘方 | `^`、`pow(x,y)`；`^` 右结合，优先于一元负号 | `2^3^2 = 512`、`-2^2 = -4` |
| 括号与符号 | `(…)`、`+x`、`-x` | `(-2)^2 = 4`、`2^-3 = 0.125` |
| 平方根、绝对值 | `sqrt(x)`、`abs(x)`，仅支持实数 | `sqrt(9) = 3` |
| 三角函数 | `sin(x)`、`cos(x)`、`tan(x)`，参数使用弧度 | `sin(pi/2) = 1` |
| 对数、指数 | `ln(x)` 为自然对数，`log(x)` 以 10 为底，`exp(x)` 为指数 | `log(100) = 2` |
| 舍入 | `floor(x)` 向下、`ceil(x)` 向上；`round(x)` 半整数远离 0 | `round(-1.5) = -2` |
| 两数比较 | `min(x,y)`、`max(x,y)`，各接受两个参数 | `max(3,5) = 5` |
| 常量与连续计算 | `pi`、`e`、`ans`；`ans` 初始为 0，失败不更新，清空会话或新建空白会话后重置，恢复时保留 | `6*7` 后输入 `ans+1` 得到 `43` |

支持小数（包括 `.5`、`1.`）和科学计数法，如 `1e3`、`2.5E-2`。小数点使用 `.`，
不接受千分位分隔符。函数和常量不区分大小写，可嵌套调用；`×`、`÷`、`−` 自动转换为
`*`、`/`、`-`。乘法需要显式写出，如 `2*pi`；`2pi` 和 `2(3)` 不合法。

## 精度与限制

- 使用 `double` 双精度实数计算，结果最多显示 **15 位有效数字**，可能采用科学计数法。
  显示位数不等于任意公式的准确位数，也不表示精确十进制或任意精度计算。
- 二进制浮点存在近似误差。例如 `0.1+0.2` 显示为 `0.3`，后续相减仍可能出现微小残差。
  连续整数精确表示范围为 `±9007199254740992`；超出后并非每个整数都能表示。
- `ans` 保留未经过显示舍入的内部数值。记录菜单的数值复制和插入使用最多 17 位有效数字，
  可往返还原同一内部值（包括负零）；这不会提高原计算精度。手动选中显示文本复制仍可能损失精度。
- 除零、非法语法、实数定义域错误和溢出会提示错误并保留输入。字面量转换下溢为 0（如 `1e-400`）
  仍拒绝输入，并明确提示下溢；过小的运算结果可能归零（如 `1e-200*1e-200`）；
  奇点附近的有限结果、消去误差和有效数字损失不会自动检测。
- 输入长度上限为 4096 个 UTF-16 代码单元，复杂嵌套另有递归限制。
  当前不支持变量赋值、复数、符号运算或精确分数。

更多说明可在插件的“精度与限制”帮助页查询。

## 兼容性

目标环境为 **Windows x64、Qt 5.15.2、MSVC v142**。请使用匹配的宿主架构和运行库，
不要用插件包覆盖宿主的 Qt DLL。

插件 ABI 与原生标签接入参考 notepad-- 源码提交
`91105f68b74382128f3313ac5af8accdc77de918`（v3.8.3 / v3.9.0 源码参考）。
源码接口参考不等于所有发布二进制都已验证；具体环境可按[使用检查清单](packaging/TESTING.zh-CN.md)确认。

## 构建与测试

安装 Qt 5.15 开发包和 CMake 后：

```bash
cmake -S . -B build/local -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON \
  -DCMAKE_PREFIX_PATH=/path/to/Qt \
  -DCALCTABDD_HOST_SOURCE_DIR=/path/to/notepad--
cmake --build build/local --parallel 4
ctest --test-dir build/local --output-on-failure --no-tests=error
```

不指定宿主源码时仅启用 `engine_tests` 和 `page_tests`。指定宿主源码后增加
`plugin_tests`；可通过 `CALCTABDD_QSCINTILLA_LIBRARY` 使用对应的预编译静态库，
否则从宿主源码构建测试依赖。正式插件不依赖另一个 QScintilla DLL。

[Windows 流水线](.github/workflows/windows.yml)在 `main` 推送、PR 和手动触发时编译
Release 并执行三个测试套件。主分支成功后发布包含 DLL、安装说明、使用检查清单、版本说明、
许可证和构建信息的预发布包，并提供 SHA256 校验文件。下载后可用
`Get-FileHash <ZIP路径> -Algorithm SHA256` 与同名 `.sha256` 文件核对。
