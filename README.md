# CalcTabdd

**在 notepad-- 里边写边算，让公式与结果一起留在标签页中。**

CalcTabdd 是一个使用 C++14 / Qt 5.15 开发的开源计算器插件。它将每次计算按“公式在上、结果在下”排列，支持十进制计算、自定义公式和程序员整数计算，适合日常计算、重复代入与位运算。名称中的 `dd` 表示 `--`。

## 主要功能

- **连续计算记录**：公式与结果上下分行，支持复制数值、复制整条计算和插入历史结果。
- **十进制与科学计算**：支持最多 50 位十进制有效数字，提供四则运算、乘方、取余及 14 个常用函数；舍入和近似计算会附来源说明。
- **自定义公式**：定义一次公式，逐行填写参数，修改数值后再次计算，适合重复代入。
- **程序员计算**：8／16／32／64 位整数与位运算，查看 DEC／HEX／BIN／OCT，完整保留整数与回绕来源。
- **快捷输入**：`@` 按模式查找数学函数、常量或整数位运算模板，支持中文关键词；`Alt+↑ / Alt+↓` 浏览历史并保留草稿。
- **记录导出与会话保存**：三种模式的混合记录可导出 TXT / Markdown；可选保存两类 `ans`、三份草稿及设置，之后恢复继续计算。
- **融入编辑器**：每个宿主窗口拥有独立计算器，界面跟随明暗配色；普通模式支持错误位置标记，内置可搜索帮助。

## 安装

当前版本为 **1.0.9**，预编译包面向 **Windows x64**。
提供普通、自定义和程序员计算，支持混合导出与 version 4 会话保存恢复。

1. 在 [Releases](https://github.com/jiy29104983/CalcTabdd/releases) 下载 Windows x64 ZIP 安装包。
2. 退出所有 notepad-- 窗口，将包内 `plugin/calctabdd.dll` 放入 notepad-- 安装目录的 `plugin` 文件夹。
3. 重启 notepad--，选择 **插件 → CalcTabdd 计算器 → 打开计算器**。

目标运行库为 **Qt 5.15.2 / MSVC v142**，请使用匹配的宿主架构和运行库，不要覆盖宿主的 Qt DLL。不同宿主版本的使用情况可参照[使用检查清单](packaging/TESTING.zh-CN.md)确认。

升级时退出宿主并替换 DLL；卸载时退出宿主并删除 `plugin/calctabdd.dll`。自行保存的会话文件会保留。

## 快速上手

### 普通计算

在底部输入公式，按 **Ctrl+Enter** 或点击 **计算**。普通模式 Enter 不提交，也不换行，编辑过程中不会自动计算。

| 输入 | 结果 | 用途 |
| --- | --- | --- |
| `(128+256)/3` | `128` | 四则运算 |
| `0.1+0.2` | `0.3` | 十进制小数 |
| `(1299+899)*0.85` | `1868.3` | 折扣计算 |
| `sqrt(3^2+4^2)` | `5` | 函数与乘方 |
| `6*7`，再输入 `ans+1` | `42`，然后 `43` | 使用上一次成功结果 |

每条记录的 **再次使用 / 修改公式** 按钮可将公式放回输入区，**记录操作** 菜单可复制或插入结果。重新提交会追加记录；含 `ans` 的公式使用当前会话的上次成功结果。计算失败时保留输入和先前的 `ans`，修正后即可重试。

### 自定义公式

例如，定义一个用于反复计算长方形面积的公式：

1. 在底部输入区切换至 **自定义公式**。
2. 在公式定义栏输入 `S=w*h`，按 **Enter** 或点击 **应用公式**。
3. 在生成的参数区逐行填写：

   ```text
   w=12.5
   h=8
   ```

4. 按 **Ctrl+Enter**，历史中会显示 `S=12.5*8` 和 `= 100`。修改参数后再次提交即可进行下一次计算。

![CalcTabdd 深色界面：S=w*h 自定义公式、逐行参数及两次面积计算记录](assets/readme/custom-formula-dark.png)

*自定义公式（深色主题）：保留公式与参数，修改数值后继续计算。*

普通模式与自定义模式分别保留草稿，共享 `ans`。修改公式仍在定义栏完成：Enter 应用，Esc 还原。参数每行一个，只接受数字、小数或科学计数法；定义中的函数与常量可用 `@` 补全。

### 常用快捷键

| 按键 | 操作 |
| --- | --- |
| `Ctrl+Enter` | 提交计算 |
| `Enter` | 普通／程序员公式区不提交、不换行；参数区换行；公式定义栏应用定义 |
| `@` | 普通／公式定义栏查找函数与常量；程序员查找 ans 和位运算，如 `@取反` |
| `↑ / ↓`、`Enter / Tab`、`Esc` | 补全列表中选择、插入、关闭候选 |
| `Alt+↑ / Alt+↓` | 向前 / 向后浏览历史，越过最新记录返回草稿 |

补全列表打开时，Enter 先插入候选；在定义栏中再按一次 Enter 才会应用定义。输入法组词期间优先处理输入法候选。

### 程序员计算

选择底部 **程序员**，设置 8／16／32／64 位和有符号／无符号，默认 32 位无符号。
输入 `(0x12 & 0x0F) << 4`，按 **Ctrl+Enter** 或点击 **计算**，得到十进制 `32`；
在 16 位设置下显示 HEX `0x0020`，点击 **展开进制详情** 查看 BIN `0000 0000 0010 0000` 和 OCT `0o40`。

![CalcTabdd 程序员深色界面：64 位整数及展开的多进制结果](assets/readme/programmer-dark.png)

*1.0.7 的真实 Qt 页面（Linux / Qt 5.15）：完整显示 64 位无符号最大值及其 HEX／BIN／OCT。*

- 支持整数 `+ - * / %`、`& | ^ ~`、`<< >> >>>` 和括号。程序员 `^` 为异或（`2^3=1`），普通／自定义仍为乘方（`2^3=8`）。
- 裸数字为十进制，`0x`／`0b`／`0o` 为原始位模式；有符号按补码解释，例如 8 位有符号 `0xFF=-1`。
- 输入越界报错，运算逐步回绕并提示；例如 8 位无符号 `(255+1)/2=0`，提示“含 8 位回绕”。
- 整数 `ans` 与普通／自定义共享的数学 `ans` 独立。修改位宽或符号不立即转换 `ans`；实际引用时须能保持原数值，否则报错并保留原值。不引用 `ans` 的表达式可按新设置计算。
- 三种模式分别保留草稿、光标和选区，程序员草稿还保留位宽与符号。历史回填恢复原模式和配置，重新提交使用当前对应 `ans`；成功后返回原草稿，失败保留待修正。
- 手动切换模式会结束历史浏览并恢复对应草稿；清空会话同时重置两类 `ans`，保留三份原草稿及设置。每个窗口独立。
- 程序员 `@` 提供 `ans` 和位运算模板，支持 `@上次结果`、`@取反`、`@按位与`、`@逻辑右移`；不提供科学函数候选。

顶部 **帮助** 按当前模式打开，也可切换查看普通／自定义或程序员规则。
程序员帮助可搜索“异或”“回绕”“ans”“会话”，分别查看整数操作和范围限制。
全部 8 种中文补全模板、整数边界及保存失败处理见[详细使用说明](packaging/README.zh-CN.md#程序员模式)。

在 **记录操作** 中，“复制纯数值”复制十进制；“复制 HEX／BIN／OCT”带进制前缀，
去掉分组和视觉换行。例如 8 位有符号 -1 复制 BIN 为 `0b11111111`。
“插入结果数值”固定插入十进制；普通／程序员的负数带括号，自定义参数保留符号。
插入程序员时，保存值本身须为当前范围内的整数，小数和越界值会被拒绝并保留输入。
数学结果带舍入或近似来源也可插入，但须满足相同检查；插入后不继承原来源。
整条复制和 TXT／Markdown 导出包含原模式、位宽、符号、公式、四进制结果及回绕来源，
详情是否展开不影响文本。

通过 **本地会话** 选择新文件，可保存混合记录、两类 `ans`、三份草稿、光标、选区和程序员设置。
默认不保存；关闭后从新的空白计算器手动恢复，不重新计算旧公式。

## 普通／自定义支持的运算

| 类别 | 运算符、函数或常量 |
| --- | --- |
| 基本运算 | `+`、`-`、`*`、`/`、`%`（取余）、`^`（乘方）、括号 |
| 基础函数 | `sqrt`、`abs`、`pow` |
| 三角函数 | `sin`、`cos`、`tan`（参数使用弧度） |
| 对数与指数 | `ln`（自然对数）、`log`（以 10 为底）、`exp` |
| 取整与比较 | `floor`、`ceil`、`round`、`min`、`max` |
| 常量与连续计算 | `pi`、`e`、`ans` |

支持 `.5`、`1.`、`1e3` 等数字写法，函数与常量不区分大小写。乘法须显式写为 `2*pi` 或 `2*(3+4)`；`%` 表示取余，不是百分比。`^` 从右向左结合，且优先于一元负号：`-2^2 = -4`，`(-2)^2 = 4`。

### 精度说明

- 十进制数最多支持 **50 位有效数字**，非零科学计数指数范围为 **-999 至 999**。十进制加、减、乘、取余在支持范围内精确计算，中间结果超限会报错。
- 每次十进制除法最多保留 50 位有效数字，取最近值，恰好居中时取偶数。例如 `1/8 = 0.125` 保持精确，`1/3` 会标明“含除法舍入”。
- `pi`、`e`、三角 / 对数 / 指数函数、非整数幂和不能精确开方的平方根使用近似计算。近似结果最多显示 17 位有效数字，**不代表 17 位都准确**。
- 使用 `ans` 或恢复会话可保留结果的类型与计算来源。复制或插入纯数值后再次提交，按新输入的十进制数字处理。

当前不支持任意精度、复数或符号求解。完整规则与示例见插件内的 **帮助 → 精度与限制**。

## 保存与导出

TXT／Markdown 支持普通、自定义和程序员的混合历史。程序员记录始终使用提交时的配置及保存值，
不随当前设置变化，不重新计算旧公式。使用过程序员的页面暂不提供会话保存或恢复，已有文件保持原样。

| 需要做什么 | 入口 | 保存内容 |
| --- | --- | --- |
| 留存或分享计算过程 | **导出记录 → 导出为 TXT / Markdown** | 已提交的公式、结果、错误和来源；程序员附原配置及四进制结果 |
| 下次继续计算 | **本地会话 → 开启保存／另存新文件…** | 记录、两类 `ans`、三种模式的草稿与设置、已确认公式及参数 |
| 继续已保存的会话 | 在空白计算器选择 **本地会话 → 恢复会话…** | 从 `.calctabdd` 文件恢复，不重新计算历史 |

计算器标签右键菜单提供“关闭计算器”，保存与分享请使用页面内的“本地会话”或“导出记录”。宿主主工具栏的复制、剪切、粘贴、撤销与重做会作用于计算器；文档保存、查找替换等入口在该标签中不可用，切回普通文档恢复。

**本地保存默认关闭**，关闭标签后如需继续，请先开启保存。同一个会话文件同时只能由一个窗口使用；当前只读写第 4 版会话格式，**第 3 版及更早文件不能直接恢复，不提供迁移**；拒绝时原文件不变。TXT / Markdown 供阅读，不能用于恢复会话。

清空会话会删除记录并重置 `ans`，不可撤销；已开启保存时也会更新会话文件。保存失败时，请在关闭标签前重试或另存。更多操作细节见[详细使用说明](packaging/README.zh-CN.md)。

## 开发与构建

依赖 **C++14 编译器、CMake 3.16+、Qt 5.15 开发包**；运行自动化测试还需要 Qt Test。

```bash
git clone https://github.com/jiy29104983/CalcTabdd.git
cd CalcTabdd
cmake -S . -B build/local -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build/local --config Release --parallel 4
ctest --test-dir build/local -C Release --output-on-failure --no-tests=error
```

若 CMake 无法找到 Qt，在配置命令中添加 `-DCMAKE_PREFIX_PATH=/path/to/Qt`。以上流程启用引擎和页面测试；宿主集成测试还需设置 `CALCTABDD_HOST_SOURCE_DIR`，指向 [notepad-- 源码](https://github.com/cxasm/notepad--)。宿主依赖的固定版本和 Windows x64 / MSVC v142 构建配置见 [Windows 工作流](.github/workflows/windows.yml)。本地页面测试不能替代 Windows 宿主中的插件加载与交互验证。

日常推送和手动运行工作流执行构建、测试及安装包校验，产物保存在 Actions 中，不自动创建 Release。
正式发布由维护者按需推送与项目版本一致的 `v<版本>` 标签触发，验证通过后发布正式 Release；不再生成预发布。
